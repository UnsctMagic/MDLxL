# Morgoth Shredder artwork

`morgoth.png` is the final transparent 4 × 4 animation sheet (RGBA, 1254 × 1254). Rows are idle/caw, walking, peck/attack, and the four-pose flying wing cycle. The renderer slices equal cells and displays the whole crowned bird at 112 × 112 CSS pixels. The original normal Shredder and updater sheets are preserved.

Created with the built-in **imagegen** tool. References: `../update/0.png` for character/style and `../update/1.png` for wing motion. The crown is painted into the character, rather than positioned as a separate graphic. The selected second output is stored here; the default generated outputs are not runtime dependencies.
