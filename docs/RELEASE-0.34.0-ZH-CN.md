# MDLxL 0.34.0 - 先看清再动手的 AI

**AI**
- **先看清，再一次改好**：在一项任务的第一次编辑之前，AI 会写下真正的问题是什么、问题影响到多大范围（常常超出你标记的区域）、哪些必须保持不变、至少两种修复方法以及它选择了哪一种。在它完成这些之前，MDLxL 会拒绝它的编辑。像"把透明度设为 0.5"这样的简单编辑不需要这一步。点击 **正在规划修改** 步骤即可阅读计划。
- **多个版本并排保留**：AI 会保留模型打开时以及每项任务开始前的样子，也可以保存自己的版本、进行比较，并用一次撤销回到任意一个版本。现在让它"回到好的那个版本"已经可行。
- **决策日志**：MDLxL 会为每个模型记住 AI 的每项任务：你的请求、AI 的选择及原因、它改了什么、结果如何，以及你之后说了什么。每项新任务都会读取最近的记录，因此 AI 之前的编辑会被当作可以撤销的选择。在 Codex 与 Claude 之间切换以及选择 **Keep a summary** 时日志都会保留；**Wipe it all** 会删除它。
- **外部检查**：当 AI 表示编辑已完成时，另一个未见过其工作的 AI 会根据你的请求、需要保留的内容清单以及前后对比图进行评判。可疑的结果会在你看到之前退回继续修改，聊天中会显示每次的结论。默认开启；每次完成编辑会多花费一次 AI 调用；可在 **连接设置** 中关闭 **外部检查**。
- **网络研究**：**Editing handbook** 旁新增了一个地球图标开关，让 AI 可以搜索网络并阅读网页，例如 Hive Workshop 教程。默认关闭。适用于 Codex、Claude Code 和 Claude API。
- **连接设置** 中新增 **思考强度**：提供商默认模型、中、**高**（默认）或极高。越高思考越仔细，也会消耗更多套餐额度或积分。
- 开启 **Editing handbook** 时，每项任务现在会附带它需要的完整指南（例如"腿穿过裙子"会附带骨骼绑定指南）。来自参考模型的规律以及你在聊天中转述的规则，会被当作需要对照你的模型核实的依据，而不是命令。
- AI 可以只拍摄相关部件的图像并使用纯色着色，更容易判断形状和缝隙。

**编辑器**
- **Glow Up**：武器光效的两个端点可以自由拖动，例如拖到锤头或斧头上，并且 **Origin brightness %** 和 **Weapon brightness %** 是两个独立的滑块。拖动控制点时动画会暂停，移动中的控制点也更容易抓取。
- **自动更新提示**：一份 MDLxL 第一次在关闭自动更新的情况下启动时，会询问一次是否在有新版本时提醒你。不点击 **更新并重启** 就不会下载任何内容。
- **CORP** 按钮的文字现在是浅色，清晰易读。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整的便携版 ZIP。
