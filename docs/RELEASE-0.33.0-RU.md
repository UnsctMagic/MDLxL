# MDLxL 0.33.0 - Обучение, Создать в Движении и Автотруп

- **Обучение**: кнопка **LER** открывает небольшое меню с пунктами **Режим обучения**, **Показывать горячие клавиши** и **Настройки обучения…**. Когда показ горячих клавиш включён, каждая кнопка и окно показывают своё сочетание маленькими зелёными буквами. Ctrl+J по-прежнему включает и выключает режим обучения. Ваши прежние настройки Shredder и свои клавиши сохраняются.
- **Alt, затем клавиша**: короткое нажатие Alt показывает буквы сочетаний, а следующая клавиша выполняет сочетание с Alt (Alt, затем R открывает Восстановление). Удержание Alt с нажатием клавиши работает как раньше.
- **Пробел всегда запускает или останавливает** анимацию, даже сразу после щелчка по флажку, кнопке, ползунку или списку. Пробел сохраняется только в текстовых полях.
- **Создать в Движении**: в Движении рядом со списком анимаций есть кнопка **Создать**. Она работает точно так же, как Создать в Анимациях.
- **EMTR открывает ваши эффекты**: если в модели уже есть ленты или частицы и ничего не выбрано, Редактор эмиттеров открывается на них, а не в Лаборатории новых эффектов.
- **Стандартные текстуры игры для эффектов**: новые искры, свечения и ленты в EMTR и вспомогательные HD-карты Forge теперь используют текстуры самой Warcraft III вместо картинок, созданных MDLxL. Модели со старыми картинками MDLxL переключаются при открытии одним шагом Отмены.
- **Автотруп (тест)**: новая кнопка **CORP** одним щелчком подгоняет труп к последнему кадру анимации Death, создаёт Decay Flesh и Decay Bone и настраивает видимость. Одна Отмена возвращает модель.
- **Вращение**: в Настройки > Мышь есть раздел Вращение, где каждый редактор может использовать **Pivot-based** (движение по кругу вокруг центра, по умолчанию) или **Линейная** (поворот по расстоянию перетаскивания). Pivot-based больше не застревает и не переворачивается, когда круг поворота виден с ребра, например поворот по Y в видах Front и Top.
- **VIS** снова классический вид MDLVis: без вкладок моделей, кнопок редакторов и консоли ИИ, с исходной строкой флажков и маленькой кнопкой **XL** для возврата.
- **Верхняя панель**: кнопки слева крупнее, панель тоньше, кнопки WC3 справа. Кнопки Скрыть/Показать удалены. В узком окне неактивные кнопки редакторов сокращаются до первой буквы, чтобы флажки отображения сохраняли свои названия.
- **Вершины**: флажок RGB Preview заменён флажком **RGB** среди флажков отображения. Он показывает цвета и затухания модели из анимации Stand.
- **Восстановление** хранит один черновик на модель и только 15 самых новых. Первый запуск этой версии один раз удаляет старые черновики (черновик после сбоя по-прежнему предлагается первым).
- **Значки файлов** теперь видны и у файлов, для которых выбрано «Всегда открывать в» MDLxL.
- Кнопки во всю ширину, стоящие друг под другом (например, Bake Sequence RGB / Bake All RGB), больше не соприкасаются.

**ИИ**
- ИИ обходится дешевле: запросы к API Claude кэшируются, у каждого запроса есть лимит шагов и необязательный лимит расходов, и каждый запрос показывает свою стоимость. Чат больше не переходит молча на ваш API-ключ после смены подключения.
- Переключатель **Editing handbook** (значок книги, по умолчанию выключен): даёт ИИ общие правила редактирования Warcraft III и пошаговые руководства. Его клавиша W.
- **Offload**: последующие сообщения сразу идут нужному помощнику, независимые части модели можно обрабатывать параллельно, а необязательная настройка позволяет простым задачам использовать более лёгкую модель.
- Картинки ИИ больше не ломаются после длинных чатов, ИИ может делать крупные планы выделения, а подгонка по выделению работает в Анимациях и Движении.
- Консоль ИИ больше не замедляет редактор во время воспроизведения анимации.

**Обновление** Откройте Настройки > Конфигурация > Проверить обновления > Обновить и перезапустить или скачайте полный портативный ZIP со страницы MDLxL.
