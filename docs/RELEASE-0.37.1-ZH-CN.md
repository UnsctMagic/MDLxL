# MDLxL 0.37.1 - UV 旋转热修复

热修复：3D 旋转规则混进了 2D UV 旋转，实在太烦人了！

- **UV 编辑器 > 旋转** 恢复到 0.36.0 之前的方式：选中部分围绕自身中心跟随鼠标，无论远近；绕圈时会一直转下去，转满一圈或更多都很轻松。**设置 > 鼠标 > 旋转** 中的 3D 旋转规则不再作用于平面 UV 图；其他地方的旋转保持不变。非正方形贴图旋转时不再被拉伸。
- **Bitz > 替换部件** 再次按新部件自身尺寸放置，居中于原部件位置；如需调整大小，可在顶点编辑器中使用缩放。
- 工具栏上的 **保存** 按钮回来了。
- **整理混乱** 在你更改选项时保持相机位置不变。
- **使用 API 密钥的 AI：** 保存密钥后立即加载模型列表，“模型”框变为下拉列表（仍可用 **Other model ID…** 手动输入）。OpenAI 的新模型可以通过 API 使用，密钥错误会说明如何修复。
- **更新：** 安装更新时会出现一个小窗口，显示进度和 Shredder 小鸟。从 0.37.1 *开始* 更新时才会首次出现。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整的便携 ZIP。
