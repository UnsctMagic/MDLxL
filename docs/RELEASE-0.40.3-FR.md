# MDLxL 0.40.3

- XFER est difficile à réussir, c'est donc un travail en cours : vérifiez chaque résultat, certains modèles devront encore être corrigés à la main.
- ANIM est retiré pour l'instant et ne reviendra que lorsqu'il sera utile.
- XFER (Transfert, F11) : donne à un modèle le mouvement d'un autre modèle. Greffe place le modèle sur le squelette de l'autre avec toutes ses animations ; Reciblage prend le mouvement partie du corps par partie du corps. Rotation, Position ou Mixte choisit comment les membres suivent. Voir le guide XFER (PDF).
- Chaque curseur a un petit − et + qui le déplacent d'un pas.
- Éditeur de sommets : le nouvel outil Couper (touche I) coupe un triangle en un nouveau point sur l'une de ses arêtes.
- Éditeur UV : Cadrer déplace les UV sélectionnés dans une zone que vous marquez sur la texture. Remplacer la texture… se trouve au bout de la ligne des matériaux. Aperçu RVB montre de nouveau le RVB de tout le modèle.
- Mouvement : Trajectoire dessine le chemin des os sélectionnés (sa couleur est dans Réglages > Apparence > Aides d’édition). Axes locaux fait tourner les poignées de Rotation avec l'os sélectionné. Les événements affichent leur nom de son, de sang ou d'apparition ; double-cliquez sur une image d'événement pour la voir dans Animations.
- Les vues Dessus et Dessous tournent autour de l'axe vertical du modèle au lieu de le renverser.
- Une animation en lecture se met en pause pendant que vous modifiez et reprend ensuite.
- Le panneau d'édition a un bouton pour le masquer. Les vues étroites affichent la barre de caméra en icônes.
- FX : les vues rapides gardent des looks tant que le modèle est ouvert, et FX s'ouvre plus vite sur les gros modèles. FX et EMTR enregistrent les images en .blp.
- EMTR : changer d'émetteur ne rejoue plus l'effet. Les zones d'émission PRE2 sont orientées correctement dans l'aperçu.
- OptimizeXL : Calculer les limites propose Complet ou Nécessaire seulement (fichier plus petit). Données inutilisées garde les couches FX en ordre. Réordonner fonctionne sur les modèles aux tables de limites de géosets courtes.
- Aide > Signaler un problème… m'envoie directement un court rapport en texte brut.
- IA : travaille sans arrêts, Voir le travail de l'IA rejoue chaque étape de l'IA dans l'éditeur, plus de fournisseurs d'IA (Claude d'abord, puis Codex) et des notes dessinées dans l'Éditeur UV et Mouvement.
- Gestionnaire de nœuds : la recherche de sons trouve les sons de toutes les extensions.

Mettez à jour via Réglages > Configuration > Rechercher des mises à jour, ou avec le ZIP portable.
