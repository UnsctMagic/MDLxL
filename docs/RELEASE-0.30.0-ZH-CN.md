# MDLxL 0.30.0 - Paint 与 UV 选择改进

- Citadel Paint：按住 Shift 并点击 **从文件…**，即可将已复制的图片导入现有裁剪工具。普通点击仍会打开文件选择器。Ctrl+V 和顶点编辑器保持不变。
- UV Wrapper：Live Select 新增默认启用的 **Grabthrough** 选项。关闭后，只选择并显示摄像机可见的顶点。点击 Grabthrough 或 Highlight Live 后，按住 A 仍可正常选择。
- UV Wrapper：打开 UV 编辑器时，N 和快速显示面板不再意外开启法线显示。已开启的法线仍可关闭，快捷键也不会再将键盘焦点移出 UV 编辑器。
- NormalsXL：**修正朝向** 可将翻转的袖口、环带和袖管朝向外侧。披风、贴花等其他开放部件保持不变。重新计算法线时会保留每个顶点自身的所有三角形，并根据平滑角度合并重合顶点的法线，从而改善拐角处的明暗。
- 编辑器中的警告会以红色闪烁一次，之后在显示期间保留红色文字和红点。重复出现的警告会再次闪烁。普通消息的外观保持不变。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整便携版 ZIP。
