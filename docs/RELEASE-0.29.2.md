# MDLxL 0.29.2 - Hotfix

Three more fixes from your reports.

**Fixes**

- OptimizeXL: the Save question is no longer cut up by the portrait frame. The whole dialog shows, the previews behind it are dimmed, and the questions and size summary are fully translated.
- Citadel Paint: every model tab keeps its own camera. Switching to another model and back no longer resets the angle and zoom, and the editor view no longer copies the previous tab's camera onto the next model.
- File > New (and closing the last tab) now starts a truly empty model instead of a starter cube.

**Update**  Open Settings > Configuration > Search for updates > Update and restart, or download the full portable ZIP from the MDLxL page.
