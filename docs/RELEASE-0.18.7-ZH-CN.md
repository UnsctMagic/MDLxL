# MDLxL 0.18.7 — 稳定的顶点移动与原始 Bitz 纹理

- 在普通视图和四视图中移动顶点时，公告板和面向摄像机的几何体现在会始终跟随指针。松开鼠标后可见位置保持不变，撤销会精确恢复原始坐标。
- “收集 Bit”和导入完整部件现在会保留每个源纹理的原始文件名、相对路径和字节，不再替换为带哈希的 MDLxL 路径，也不会把普通图像转换为 TGA。发生文件名冲突时，已有文件不会被覆盖。
- 现在可以在关键帧框下方拖动动画时间轴，同时保留对附近关键帧的吸附。
- Showcase 原来的“Hive”录制配置现已更名为“Low Size”。

下载 **MDLxL-0.18.7-win32-x64.zip**，解压整个 ZIP，然后运行 **MDLxL.exe**。请将所有文件夹放在一起。FFmpeg 对应源代码压缩包可在发布页面单独下载。
