# MDLxL 0.24.1 - Плавная скорость анимации

## Скорость анимации

- Перетаскивание ползунка скорости анимации больше не тормозит. Анимация пересчитывается один раз, когда вы отпускаете ползунок, и каждое перетаскивание — один шаг отмены.
- У каждого ползунка скорости (Animation Actual Speed, Master Controller и у каждой анимации в Adjust All Speed) теперь есть числовое поле. Введите скорость от 1 до 300% и нажмите Enter.
- Пока новая скорость записывается, под ползунком отображается тонкая полоса.
- Параметр Remember Original Timing удалён. Изменение скорости сохраняется только как настоящий тайминг модели, без дополнительных данных MDLxL в файле, поэтому после повторного открытия скорости модели показываются как 100%. Данные тайминга, сохранённые прежними версиями, удаляются при следующем сохранении модели.

## Обновление

В 0.24.0 откройте Настройки > Конфигурация > Проверить обновления > Обновить и перезапустить.
