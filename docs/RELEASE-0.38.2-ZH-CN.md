# MDLxL 0.38.2 — 热修复

- 便携版下载现使用永久文件名 `MDLxL-win32-x64.zip`。同一个最新版本下载链接也将用于后续版本。本版本替代已撤回的 0.38.1 热修复版本。
- 保存恢复数据时，编辑器菜单和面板响应更流畅。恢复数据保留完整的撤销历史和已完成的绘画笔触，关闭时也会保存。
- 切换模型标签页或 Showcase 画质时，不再保留旧预览和相机监听器。共享纹理查询可避免重复工作，同时仍能识别文件变化。
- UV Wrapper 拖动实时更新，开销更低。Rotate 无阻力地跟随鼠标直线和圆周运动；单个部件原地旋转，多个部件围绕共同中心旋转，并支持按住 Shift 进行精细调整。FX 纹理贴合和 3D 旋转设置保持原有操作方式。
- UV Wrapper 的 Zoom 恢复此前的收拢行为。预览变化保留相机位置并避免不必要的网格重绘；Wrapper 布局仍与 FX 纹理贴合相互独立。
- 在 OptimizeXL 中浏览问题和修复预览时，保持原来的播放或暂停状态。末尾未使用的枢轴点可通过 Preview fix、所选修复或 Fix everything 修复；使用 Back 返回后，组合预览仍可正常工作。
- 小尺寸 MDL/MDX 文件图标的文字更清晰。Select through 会在重启后保留。
- 界面和诊断支持法语和德语。新版本说明使用英语、西班牙语、俄语、简体中文、法语和德语；现有版本说明和历史 PDF 指南保持不变。
- Settings 说明游戏资源预加载为可选操作，并会占用磁盘空间。

通过 Settings > Configuration > Search for updates > Update and restart 更新，或从 MDLxL 页面下载完整便携 ZIP。
