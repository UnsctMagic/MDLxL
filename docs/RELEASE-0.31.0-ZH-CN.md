# MDLxL 0.31.0 - AI 控制台与全新外观

- **AI 控制台**：与能编辑模型和动画的 AI 对话。它停靠在工作区左侧（拖动边缘可调整宽度），工作时实时显示思考过程，你也可以在任务中途调整方向。在控制台顶部选择 AI 模型。
- AI：用 **Marker**、**Pen** 和 **橡皮擦** 在 3D 模型上作画，向 AI 说明你的意思。画的内容永远不会改动模型或已保存的文件。Ctrl+Z / Ctrl+Y 同样可以撤销绘画；选择任意编辑工具会收起绘画工具。
- AI：**Offload Mode**（默认开启）把每项任务交给单独的工作对话，让长时间的会话保持流畅。保存时可以保留、总结或清除这些对话。切换模型标签页会暂停 AI，切回时继续。
- AI：如果 AI 的某次编辑会导致模型无法保存，会立即撤销并说明原因。替换已有文件前总会先询问你。

- **全新外观**：工具改为雕刻风格的方块和全新手绘图标，顶部一行换上新图标，模块栏改为石板灰与金边，配方形魔兽争霸 III 图标。AI 按钮是模块栏的第一个图标（伊利丹的恶魔变身）。当前工具以主题强调色发光；可在 设置 > 外观 > 界面 > Tool highlight 中自选颜色。
- 全新外观：显示开关（阴影、骨骼、发射器、网格…）现在是顶部一行的图标按钮，亮起即为开启。窗口较窄时只显示图标，悬停可看名称。
- 全新外观：Stats 和坐标可收起到细标题栏下（收起后的 Stats 仍显示顶点、选择和三角形数）。几何集可用 ⇱ 浮动到视图上方，用 ⇲ 停靠回去。
- 全新外观：所有窗口和对话框（设置、各资源管理器、粒子编辑器、AnimXL、整理混乱、Attachemator、Citadel Paint、库、BitsAndParts）都使用与主窗口一致的柔和圆角卡片、按钮和标签页。
- 全新外观适用于全部七种主题。**VIS** 依旧是原汁原味的经典 MDLVis 外观，保持不变；在那里 AI 图标位于 XL 旁边。
- **Shift+F1** / **Shift+F2** 在深色与浅色外观之间切换。切回时会完全恢复你自己的外观，包括自定义颜色。两个按键都可在 键盘快捷键 中修改。

- 几何集带有重复几何体动画的模型现在会直接在编辑器中打开。状态栏中的小按钮 **⚠ 重复的几何体动画** 提供 **Fix**（可用 Ctrl+Z 撤销）或 **暂不**。
- 覆盖保存只读文件（例如从 zip 中打开的文件）时，现在会询问保存位置，而不是直接失败。
- 在顶点编辑器和 Forge 中拖动顶点时，坐标会实时跟随选择。
- UV Wrapper：Live Select 旁新增一个小 ▾ 菜单，包含 **线条**（新增，取消勾选可隐藏顶点之间的连线）和 **穿透选择**。
- 材质管理器和粒子设置中的纹理菜单现在只显示纹理文件名，不再显示完整路径。
- 更新安装成功后，MDLxL 会发送一次匿名信号，只包含新的版本号，用于统计更新次数。不会发送或保存任何其他内容。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整的便携版 ZIP。
