# MDLxL 0.30.0 - Улучшения Paint и выделения UV

- Citadel Paint: удерживайте Shift и нажмите **Из файла…**, чтобы открыть скопированное изображение в существующем инструменте обрезки. Обычный щелчок по-прежнему открывает выбор файла. Ctrl+V и редактор вершин не изменены.
- UV Wrapper: у Live Select появился флажок **Grabthrough**, включённый по умолчанию. Отключите его, чтобы выделять и показывать только видимые с камеры вершины. Удержание A работает после нажатия Grabthrough или Highlight Live.
- UV Wrapper: N и панель быстрого отображения больше не включают нормали случайно, пока открыт редактор UV. Уже включённые нормали можно отключить; сочетания клавиш сохраняют фокус в редакторе UV.
- NormalsXL: **Исправить направление** разворачивает вывернутые манжеты, пояса и рукава наружу. Другие открытые части, например плащи и декали, остаются нетронутыми. При пересчёте нормалей сохраняются все собственные треугольники каждой вершины, а угол сглаживания определяет объединение совпадающих вершин. Это улучшает освещение углов.
- Предупреждения в редакторе один раз вспыхивают красным, затем сохраняют красный текст и красную точку, пока отображаются. Повторные предупреждения вспыхивают снова. Обычные сообщения выглядят как раньше.

**Обновление** Откройте Настройки > Конфигурация > Поиск обновлений > Обновить и перезапустить или скачайте полный переносимый ZIP со страницы MDLxL.
