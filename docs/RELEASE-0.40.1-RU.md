# MDLxL 0.40.1

- Вершины: открываются с включённым RGB, поэтому цвета геосетов совпадают с Анимациями, Костями и Движением.
- Вершины и Анимации: слои Аддитивный гаснут вместе со своей прозрачностью; каждая текстура сохраняет своё повторение (Wrap Width и Wrap Height), как в игре.
- Анимации: переключатель Тени работает.
- Редактор текстур: «Собрать текстуры» сохраняет файлы текстур модели в один ZIP.
- UV-развёртка: Кубическая проекция, Цилиндрическая проекция, Выпрямить, Зеркальная копия, Развернуть и Расслабить. Элементы карты и текстуры находятся в заголовке окна; предупреждения появляются поверх UV-карты.
- MDLxL запускается с пустым рабочим пространством вместо безымянной модели.
- Кнопки подсвечиваются, когда щелчок изменяет модель. Элементы, которые не могут сработать, скрыты или затенены. Отмена работает в менеджере Витрины.
- OptimizeXL удаляет мелкие линейные повороты, сдвигающие сетку не более чем на 0,25 %.
- Консоль ИИ: Claude Code использует собственный вход Claude Code на этом ПК.

Обновление: Настройки > Конфигурация > Проверить обновления, или портативный ZIP.
