# MDLxL 0.32.0 - ИИ работает в фоне

- **ИИ работает в фоне**: ИИ продолжает работать над своей моделью, пока вы открываете и правите другие модели. Его правки попадают во вкладку этой модели как обычные шаги отмены; ваш Ctrl+Z во вкладке, с которой вы работаете, их не трогает.
- **Несколько заданий ИИ одновременно**: чат каждой модели выполняет своё задание. Отправьте запрос в одной модели, переключитесь на другую и отправьте ещё один. Остановка и уточнения действуют на чат, который сейчас открыт.
- ИИ: проверочные снимки рисуются вне экрана, поэтому ваш вид и камера не двигаются, пока ИИ смотрит на модель. Шаги, которым нужен экран (например, Сохранить), ждут, пока вы вернётесь во вкладку этой модели.
- ИИ: MDLxL теперь находит Codex и Claude Code на любом ПК с Windows, включая копии внутри их настольных приложений, и сам восстанавливается, если обновление их перемещает.
- ИИ: Pen, Marker и Ластик всегда показывают, какой инструмент сейчас у мыши. Щелчок средней кнопкой для вращения камеры убирает инструмент рисования, а выбор инструмента рисования возвращает рабочий режим, чтобы он действительно рисовал.

- **Значки файлов**: в Настройки > Конфигурация > File icons теперь отдельные строки для **MDL files** и **MDX files**, по пять новых значков с подписью для каждого (синий MDL, красный MDX). Текущий значок остаётся, пока вы его не смените.
- UV-развёртка теперь открывается с видом спереди и вписывает модель в окно.
- Четыре вида: панель вида больше не закрывает названия окон.
- Выпадающие списки (список языков, меню Triangles в UV, меню ключевых кадров и костей) теперь следуют теме, а не белеют в тёмных темах.
- Русский: «UV-развёртки» теперь «UV-карты», а кнопки отображения в узком окне называют себя во всплывающей подсказке.

**Обновление** Откройте Настройки > Конфигурация > Проверить обновления > Обновить и перезапустить или скачайте полный портативный ZIP со страницы MDLxL.
