# MDLxL 0.20.0 — Обновления, возврат версии и переводы

MDLxL теперь умеет проверять наличие следующего выпуска. Эта сборка также включает все улучшения Forge, SHAPE и редакторов из версии 0.19.0.

- **Обновления:** в Настройки → Мышь появились **Проверить обновления** и **Автообновление**. По умолчанию автообновление выключено. При включении программа проверяет обновления один раз при запуске и предлагает новую стабильную версию. Загрузка и установка начинаются только после выбора **Обновить и перезапустить**.
- **Список изменений:** окно обновления показывает краткий список на вашем языке. Полная запись опубликована на [Low Polyworks](https://www.lowpolyworks.com/mdlxl/?version=0.20.0&lang=ru); сверху можно выбрать английский, русский, испанский или упрощённый китайский.
- **Вернуться к предыдущей версии:** после каждого успешного обновления сохраняется ровно одна предыдущая версия программы. Её можно восстановить из настроек без интернета. Следующее успешное обновление заменяет эту копию. Текущие настройки, личные библиотеки, записи и сохранённые файлы сохраняются при обновлении и возврате. Перед перезапуском MDLxL спрашивает о несохранённой работе.
- **Переводы:** новые элементы управления, подсказки, сообщения редакторов и окна обновления переведены на русский, испанский и китайский. Существующие переводы сообщества сохранены.
- **Официальный сайт:** в справке, информации о программе и окне обновления появилась небольшая ссылка Low Polyworks. Начинайте загрузку со [страницы MDLxL](https://www.lowpolyworks.com/mdlxl).

## Также включено из 0.19.0

- **Forge и SHAPE:** наглядные плитки примитивов, размеры, толщина, умеренная сложность и шлем ThumperXL; текстуры и вырезы Projector; предварительный просмотр Curve, Fold, Twist, Dome, Roll и Taper с автоматическими опорными рядами для грубой геометрии.
- **BITZ и EMTR:** размещение деталей в Quad View с сохранением привязок к костям, палитры RGB для каждой анимации и упорядоченные папки моделей; независимые рабочие копии библиотечных эффектов и разделение конфликтующих путей текстур.
- **Материалы и UV:** отменяемое объединение Sort My Mess с просмотром До/После; временные UV-текстуры допускают обычное редактирование геометрии, сохраняют исходные параметры материалов и изменения геометрии/UV при возврате текстуры; ускоренная начальная прокрутка UV без наложения цвета команды на фон.
- **Редактор и запись:** изменение высоты списков геосетов; частицы и ленты отображаются в Animations без маркеров редактирования; временные кадры GIF сохраняются на диске назначения записи.

## Как получить выпуск

Откройте [www.lowpolyworks.com/mdlxl](https://www.lowpolyworks.com/mdlxl), скачайте переносимый ZIP для Windows, распакуйте папку целиком и запустите **MDLxL.exe**. Сохраняйте папки программы вместе. Для сборок без функции обновления сначала нужна эта загрузка; следующие обновления можно устанавливать из настроек. На странице также доступна ссылка на архив соответствующего исходного кода FFmpeg.
