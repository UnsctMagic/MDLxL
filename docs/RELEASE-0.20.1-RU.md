# MDLxL 0.20.1 — Выбор файлов в менеджере текстур

- **Выбор текстур:** кнопка **Resolve from folder…** в менеджере текстур теперь показывает поддерживаемые файлы BLP, TGA, DDS, PNG, JPG/JPEG и WebP. Можно выбрать несколько файлов сразу.
- **Загрузка в модель:** выбранные файлы загружаются в текущий сеанс. Существующие пути текстур сохраняются; для файлов с новыми именами добавляются записи текстур.
- **Поиск по папке сохранён:** команда File → **Resolve textures from folder** по-прежнему ищет в выбранной папке пути, уже указанные в модели.

Модели Warcraft III ссылаются на внешние файлы текстур. При передаче модели сохраняйте выбранные файлы вместе с ней. Автообновление остаётся добровольным: проверка при запуске работает только после включения, а установка начинается лишь после выбора **Update and restart**.
