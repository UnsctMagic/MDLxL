# MDLxL 0.33.0 - 学习、运动中创建和自动遗骸

- **学习**：**LER** 按钮打开一个小菜单，包含 **学习模式**、**显示快捷键** 和 **学习设置…**。开启显示快捷键后，每个按钮和窗口都会用绿色小字显示其快捷键。学习模式默认关闭；可通过 LER 或 Ctrl+J 开启。原有的 Shredder 设置和自定义按键会保留。
- **先按 Alt，再按一个键**：轻按一下 Alt 会显示快捷键字母，接下来按的键会执行对应的 Alt 快捷键（先按 Alt 再按 R 打开恢复）。按住 Alt 同时按键的方式不变。
- **空格始终播放或停止** 动画，即使刚点击过复选框、按钮、滑块或下拉列表。只有文本框会保留空格输入。
- **运动中创建**：运动的动画列表旁新增 **创建** 按钮，与动画中的创建完全相同。
- **EMTR 打开已有效果**：如果模型已有丝带或粒子且没有选中任何内容，发射器编辑器会直接打开它们，而不是新效果的实验室。
- **效果使用游戏原有贴图**：EMTR 中新建的火花、光晕和丝带，以及 Forge 的 HD 辅助贴图，现在使用 Warcraft III 自带的贴图，而不是 MDLxL 生成的图片。使用旧版 MDLxL 图片的模型在打开时会自动切换，作为一步撤销。
- **自动遗骸（测试）**：新的 **CORP** 按钮一键把遗骸贴合到 Death 动画的最后一帧，创建 Decay Flesh 和 Decay Bone，并设置可见性。一次撤销即可恢复模型。
- **旋转**：设置 > 鼠标 中新增旋转部分，每个编辑器可选择 **Pivot-based**（绕中心画圈，默认）或 **线性**（按拖动距离旋转）。当旋转圆从侧面看过去时（例如 Front 和 Top 视图中的 Y 轴旋转），Pivot-based 不再卡住或翻转。
- **VIS** 恢复为经典的 MDLVis 布局：没有模型标签、编辑器按钮和 AI 控制台，使用原来的复选框行，并有一个小的 **XL** 按钮切换回来。
- **顶部栏**：左侧按钮更大，栏更细，WC3 按钮位于右侧。隐藏/显示按钮已移除。窗口较窄时，未激活的编辑器按钮缩短为首字母，让显示复选框保留完整名称。
- **顶点**：RGB Preview 复选框改为显示复选框中的 **RGB** 复选框，显示模型在 Stand 动画中的颜色和淡入淡出。
- **恢复** 每个模型只保留一个草稿，且只保留最新的 15 个。此版本首次启动时会清除一次旧草稿（崩溃留下的草稿仍会优先提供）。
- **文件图标**：设置为“始终使用” MDLxL 打开的文件现在也会显示图标。
- **Showcase 背景** 只用于 Showcase：即使在 Showcase 中选过背景，动画和运动也始终显示正常视图。
- 上下堆叠的整宽按钮（例如 Bake Sequence RGB / Bake All RGB）不再紧贴在一起。

**AI**
- AI 更省钱：Claude API 请求会被缓存，每个请求有步数上限和可选的花费上限，并显示每个请求的费用。切换连接后，聊天不会再悄悄改用你的 API 密钥。
- **Editing handbook** 开关（书本图标，默认关闭）：为 AI 提供通用的 Warcraft III 编辑规则和分步指南。快捷键为 W。
- **Offload**：后续消息直接发送给正确的助手，模型中互不相关的部分可以并行处理，可选设置允许简单任务使用更轻量的模型。
- 长时间聊天后 AI 截图不再失败，AI 可以对选区进行特写，适应选区在动画和运动中也能使用。
- 播放动画时，AI 控制台不再拖慢编辑器。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整的便携版 ZIP。
