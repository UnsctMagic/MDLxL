# MDLxL 0.35.0 - 枢轴一目了然

**运动与骨骼**
- 在预览中**双击模型的某个部分**（运动、骨骼或动画）：会选中该部分所挂的骨骼，并打开**聚焦骨架**，即使骨骼和聚焦骨架原本是关闭的。
- **枢轴十字**：聚焦骨架高亮的每根骨骼都会在枢轴处显示它自己的 X（红）、Y（绿）、Z（蓝）轴。十字随骨骼一起转动，播放时很容易看清旋转。
- **控制器类型**现在以小下拉框的形式放在“控制器”标题里。**Multiselect from List** 已移除，因为多选始终开启：Shift+单击添加，Ctrl+单击移除，普通单击只选中该对象，预览和对象列表中都一样。

**顶点**
- **Zoom Align**（Shift+1，粉色）：使用缩放工具框选一个已选中的顶点，然后放大。其余选中的点会滑动，直到从你的视角看每个点都对齐在粉色顶点后面，同时保持与视点的距离，因此从这个角度看，弯曲的表面会变平。锚点（1，绿色）和 Align 一次只能用一个。

**编辑器**
- **另存为 > 模型名称**：直接在另存为窗口中设置保存在模型内部的名称，与文件名分开。
- **Glow Up** 在预览下方显示 EMTR 的**暂停 / 播放**按钮（空格键作用相同），可以在动画静止时摆放发光的两端。
- **欢迎窗口**：首次启动时关于自动更新的询问，现在是一个带简短号角声的 MDLxL 小欢迎窗口，而不是 Windows 警告框。
- **帮助 > 关于** 成为真正的“关于”：版本、MDLxL 是什么、谁制作的、致谢以及它所使用的组件。
- **帮助 > Check model** 已移除；它只显示一个空列表。
- **翻译已跟上**：西班牙语、俄语和中文现在覆盖了最近几个版本新增的文字。中文补上了约 3000 条仍是英文的文字。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整的便携版 ZIP。
