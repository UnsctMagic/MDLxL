# MDLxL 0.38.0

**布局与几何集**
- 模型控件移到顶部工具栏：MDX 转换和 DPI/Scroll 位于语言、队伍颜色和 **平滑** 旁边。打开的模型显示为底部的标签页。**设置 > 附加组件…** 打开附加组件面板。不再显示日常状态消息；错误会在时间轴上方短暂出现。
- **紧凑集** 成为新的默认几何集列表：用编号方框代替勾选列表。**设置 > 外观 > 界面** 提供 **紧凑集**、**经典集** 和 **紧凑集颜色**。VIS 始终显示 **经典集**。
- 几何集分组改为标签页，不再使用下拉框。**新建标签页**（+）和 **标签页** 操作位于 **几何集** 标题中。
- 右键单击几何集可选择 **隐藏几何组** 和 **始终显示**。开启 **隐藏多余项** 时，把几何集的可见性烘焙为 0 不会再让它在工作中从列表消失。
- 所有工具栏使用同一套基于 MDLVis 的图标（手 = **移动**，马蹄铁 = **旋转**，放大镜 = **调整大小**），当前工具仍会高亮。
- 右键单击 **骨骼** 可在骨骼、运动、动画、POSE 和 VIS 中选择 **辅助对象** 和 **骨骼**。视图在 VIS 和 XL 中显示相同的控件。

**移动与旋转**
- **工作平面约束**：所有 3D 编辑器中的 **移动** 和 **旋转** 共用一个操纵器，遵循 MDLVis。四视图中，前/顶/侧每个窗格使用自己的平面；透视视图保留 XY/ZX/YZ 选择。
- 受约束移动时按住 Shift，指针旁会显示带锁定轴的橙色挂锁。
- 所有拖动每帧只更新一次：UV Wrapper、网格移动和相机旋转不再延迟。松开鼠标的位置不变。
- 四视图中移动顶点不再延迟，正交视图中的几何体也不再消失。
- UV Wrapper：**缩放** 在任意拖动方向上都能放大或缩小选区；**旋转** 随鼠标一比一转动，不受 3D 旋转设置影响。**线条** 和 **穿透选择** 直接位于 **实时选择** 旁边。
- 运动和动画：**绕轴旋转** 框位于 **当前序列** 下方。

**特效**
- **FX**（全局动画制作器）让模型部件拥有在各自全局序列上运行的持久效果，例如发光符文、流水或地形表皮。每种效果有自己的图层和 **循环时长**；**在 EMTR 中打开** 会在完整编辑器中打开其发射器。
- EMTR 添加特效的方式与添加飘带相同：从 **库** 中选择特效，它会放在所选顶点及其骨骼上，然后 **创建** 或 **取消**。浏览方式与主库相同。
- EMTR 新建的武器飘带使用暴雪的武器拖尾图片，挥动时明亮的边缘会留在武器上。
- **发射器编辑器** 的 **运动** 标签页可用于没有动画的模型；**在播放头处放置爆发** 会说明需要先添加动画。
- Sphereomancer 编辑时预览保持稳定，从模型自身的碰撞形状开始，提供预设（默认 **x2 标准单位**）以及 **添加球体** / **添加方框**。每个形状都有可拖动的编号方框。

**库与部件**
- **库** 中的纹理和所有纹理选择器在 **标准** 旁提供 **世界编辑器样式**（默认）：像浏览模型一样按世界编辑器条目浏览纹理。
- Bitz **替换部件** 会沿用被替换部件的可见性；整体导入会获得标准的尸体可见性。
- 在保存、骨骼、运动/动画、**管理器** 和 **展示** 之前，**修复模型** 提示会修复魔兽争霸 III 只能存为关键帧的数值。此前这类模型无法保存。
- 顶点侧边栏：当几何集使用相同材质时，**核焊接** 会合并位于同一位置的所选顶点。**按松散部件分离** 和 **完全分离** 位于同一行。
- Auto Corpse：抓取的部件有一个用于升高或降低的手柄，在任意 **大小** 下拖动都会跟随鼠标。

**AI**
- 移除了 Offload 小鸟。每个模型标签页保留自己的直接聊天；多个可同时工作，旧聊天仍可打开。
- AI 用 **几何集** 列表中显示的编号称呼几何集，一步查到编辑器函数，并能在每个动画的每一帧上检查规则。

**修复与启动**
- 如果 Windows 无法启动 WebGL，MDLxL 会自动用软件渲染重试一次，无需修改快捷方式。
- 双击打开的模型会在已安装的 MDLxL 中打开，而不是最后运行过的测试副本。
- Forge 的 **添加形状** 菜单可再次通过第二次单击、点击外部或 Escape 关闭。语言菜单不再被肖像工具栏遮挡。
- 查看控件显示为 **播放速度**；修改模型时间的控件显示为 **动画速度**。
- 方形顶点点不再被混合材质遮挡。
- **帮助 > 模型检查** 只显示 Hive 检查器的结果，不再混入 MDLxL 自己的结构警告。
- 更新：此版本也接受从 0.39.0 开始使用的固定下载文件名。更旧的副本必须先更新到 0.38.0。
