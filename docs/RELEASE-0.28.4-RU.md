# MDLxL 0.28.4 - Срочное исправление

**Исправления**

- В режиме Bones появилась одна компактная строка флажков Bones / Helpers / Refs под списком Object и над Multiselect. Выбранная видимость сохраняется после повторного открытия редактора.
- Точки Refs снова можно выбирать, перемещать и редактировать. Команда Create > Ref создаёт точку привязки и сразу показывает её. В VIS все три типа всегда включены, а строка флажков скрыта.
- Bones остаются зелёными, Helpers — фиолетовыми, Refs — розовыми. У каждого набора Appearance свои цвета. Для текста на белом фоне используются тёмно-зелёный, фиолетовый и розовый цвета с тонкой чёрной обводкой. Цвета текста настраиваются в Appearance > Lists & folders, а 3D-маркеров — в Bones & skeleton. Выпадающие списки сохраняют обычный вид; у списка Object маленькая чёрная стрелка.

**Обновление**  Откройте Settings > Configuration > Search for updates > Update and restart или скачайте полный переносимый ZIP с сайта MDLxL.
