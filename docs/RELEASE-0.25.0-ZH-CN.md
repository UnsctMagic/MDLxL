# MDLxL 0.25.0 - 肖像编辑器、隐藏额外几何集、更干净的 BITZ 与 RGB 粘贴

## 肖像

- 运动模式中新增肖像相机编辑器。肖像框视图通过模型的肖像相机显示模型，与游戏底部面板中的显示一致。用鼠标旋转和缩放，然后点击设置当前视图保存镜头。可以撤销。
- 新建相机会添加一台对准头部和肩膀的相机。如果模型没有 Portrait 动画，"No Portrait animation · Create" 链接可以创建一个。
- "⋯" 菜单中有更多控制：相机名称和数值、镜头预设、Front 与 Level 镜头、游戏肖像光照、构图参考线，以及 Idle/Talk 切换。

## 几何集

- 反转按钮换成了 Hide extras（隐藏额外）。点击一次即可在几何集列表和视图中隐藏尸体和肖像背景几何集（在 Stand、Walk、Attack 中从不显示的几何集）。不会删除任何内容，再次点击即可恢复。反转仍在右键菜单中。

## BITZ

- 替换部件现在在顶点编辑器中放置部件。应用替换会把它放在被替换部分的中心，保持选中并启用移动工具，可用常规顶点工具摆放。骨骼和权重仍然来自被替换的部分。
- BITZ 和 Collect Bit 预览重新可以用鼠标旋转。

## 动画

- 从其他模型粘贴的几何集只会得到一个固定 RGB 颜色，不再带入全局序列，因此不会再出现重复的全局序列。
- Set Sequence、Set All 和 Bake RGB 现在可用于使用全局序列的轨道。

## 更新

在 0.24.2 中，打开设置 > Configuration > 检查更新 > 更新并重启。
