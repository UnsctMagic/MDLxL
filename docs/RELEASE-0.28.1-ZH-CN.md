# MDLxL 0.28.1 - 紧急修复

## 修复

- UV 包裹器：更换材质后纹理图重新绘制时，黄色纹理警告不再闪烁，工作区也不再跳动。这在较慢的电脑上最明显。
- 粒子库：全部 34 个已审核的效果名称已恢复（例如“Low black smoke”和“Narrow flame column”）。其中 11 个曾变回自动名称。现在只要游戏中的模型没有变化，重建粒子库或 Warcraft III 更新后，已审核的名称仍会保留在对应效果上。
- 无法预览的生成效果提示，在所有模型格式（包括 1800）下都重新有西班牙语、俄语和中文翻译。
- 锻造：添加锻造部件不再改变模型其他几何体集已保存的边界。

## 更新

在 0.28.0 中，打开 设置 > 配置 > 检查更新 > 更新并重启。
