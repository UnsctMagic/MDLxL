# MDLxL 0.40.2

- Désolé : la 0.40.1 annonçait que les couleurs de Sommets étaient corrigées, mais avec l'anticrénelage activé elles ne correspondaient toujours pas à Animations. Cette mise à jour corrige cela.
- Sommets : les couleurs des geosets (RGB) et les calques transparents s'affichent comme dans Animations quand l'anticrénelage est activé. Avant, les rouges paraissaient orangés et délavés.

Mettez à jour via Réglages > Configuration > Rechercher des mises à jour, ou avec le ZIP portable.
