# MDLxL 0.20.1 — 纹理管理器文件选择

- **选择纹理文件：**纹理管理器中的 **Resolve from folder…** 现在会显示受支持的 BLP、TGA、DDS、PNG、JPG/JPEG 和 WebP 文件，并允许一次选择多个文件。
- **载入模型：**选中的文件会载入当前会话。已有的纹理引用保留原路径；新文件名会添加为纹理条目。
- **保留文件夹查找：**File → **Resolve textures from folder** 仍会在所选文件夹中查找模型已经引用的路径。

Warcraft III 模型引用外部纹理文件。分享模型时请一并保留所选纹理。便携版更新功能仍需用户主动启用：只有开启后才会在启动时检查更新，并且只有选择 **Update and restart** 后才会安装。
