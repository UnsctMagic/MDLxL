# MDLxL 0.28.3 - Срочное исправление

**Исправления**

- Collect Bit: сохранение больше не прерывается, если в BitsAndParts уже есть другая текстура по тому же пути. Собранная деталь сохраняется только в MDX с точными исходными путями текстур. Файлы текстур не копируются и не перезаписываются.
- Теперь деталь можно собрать, даже если её текстуры не загружены. Геометрия, материалы, UV-координаты и дорожки анимации RGB сохраняются.

**Обновление**  В версии 0.28.2 откройте Settings > Configuration > Search for updates > Update and restart.
