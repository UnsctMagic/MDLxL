# MDLxL 0.29.2 - Срочное исправление

Ещё три исправления по вашим сообщениям.

**Исправления**

- OptimizeXL: вопрос «Сохранить» больше не разрезается рамкой портрета. Окно видно целиком, предпросмотры за ним затемняются, а вопросы и сводка размера полностью переведены.
- Citadel Paint: каждая вкладка модели хранит свою камеру. Переход к другой модели и обратно больше не сбрасывает угол и масштаб, а вид редактора больше не переносит камеру предыдущей вкладки на следующую модель.
- Файл > Новый (и закрытие последней вкладки) теперь создаёт действительно пустую модель вместо стартового куба.

**Обновление**  Откройте Settings > Configuration > Search for updates > Update and restart или скачайте полный переносимый ZIP с сайта MDLxL.
