# MDLxL 0.40.1

- Vertices: opens with RGB on, so geoset colours match Animations, Bones and Movement.
- Vertices and Animations: Additive layers fade with their alpha; each texture keeps its own Wrap Width and Wrap Height, as in the game.
- Animations: the Shadows switch works.
- Texture Manager: Bundle Textures saves the model's texture files in one ZIP.
- UV Wrapper: Box Projection, Cylinder Projection, Straighten, Mirror Copy, Unwrap and Relax. Map and texture controls sit in the title bar; warnings float over the UV map.
- MDLxL starts with an empty workspace instead of an untitled model.
- Buttons light up when a click edits the model. Controls that cannot act are hidden or greyed. Undo works in the Showcase manager.
- OptimizeXL removes small linear turns that move the mesh at most 0.25%.
- AI console: Claude Code uses this PC's own Claude Code sign-in.

Update: Settings > Configuration > Search for updates, or the portable ZIP.
