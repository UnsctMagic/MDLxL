# MDLxL 0.21.2 — 0.21.1 热修复

本次热修复提供完整的 MDLxL 便携版软件包。它修复了两个编辑器问题，并保留原有贴图路径和模型数据。

- 使用 EMTR 插入魔兽争霸 III 原生特效时，会保留资源库中贴图的原始路径，不再为这些贴图创建新路径。
- 对 UV 进行小幅编辑时，UV Wrapper 的实时模型预览会保持显示；预览替换贴图期间也是如此。
- MDLxL 0.21.1 用户使用 **搜索更新** 或开启启动时检查后会看到此热修复。选择 **更新并重启** 会下载并验证完整的 0.21.2 ZIP 包。
- 如果当前安装版本受到之前更新程序问题的影响，请从 [Low Polyworks](https://www.lowpolyworks.com/mdlxl/) 下载并解压完整软件包。
