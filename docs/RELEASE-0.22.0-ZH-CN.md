# MDLxL 0.22.0 - POSE 动画工具与编辑改进

## 开始摆姿势
1. 打开 **Movement (F3)**，选择动画和帧，然后点击 **POSE**。
2. 点击手、脚或身体控制柄，使用 **Move** 或 **Rotate**。移动 **Bend** 来调整肘或膝的朝向。可以直接拖动控制柄、抓住箭杆，或使用小方块在对应平面内移动。
3. 移动 Body/Pelvis 来调整整个相连角色的姿势。选中手、脚或蹄后，点击旁边的 **Pin** 将其固定；点击 **Pinned** 解除固定。
4. **Add** 新建控制柄：选择图标，点击骨骼，检查高亮链条，再点 **Add handle**。使用 **Adjust chain** 设置 Start、End 和弯曲关节。**Setup** 编辑已有控制柄。设置时可直接在视图中选择骨骼并旋转相机。
5. 红色准星会在阻止移动的控制柄上闪烁。解除固定或调整姿势；准星按钮可开关提示。原有的骨骼编辑方式仍可使用。

自动识别结合骨架、几何和已有动画。特殊骨架仍可能需要 Add/Setup。每次完成拖动都会写入原生动画关键帧，并支持撤销。照常保存即可。

## 其他改进
- 上半身与骑手控制保持连接；改进复杂骨架识别；加快大型动画模型的姿势编辑。
- 平面小方块位置固定，箭头尺寸有上限，按下时显示对应颜色的霓虹高亮。POSE 会记住自己的显示设置，关闭后恢复普通视图。
- **Fix and paste** 可修复粘贴引用。同材质的 geoset 合并可选择如何解决冲突。
- UV 投影保留所选 geoset 的相对位置。**Triangles** 在所选面的原始边界内细分。
- **Vibe** 搜索改进匹配效果与输入响应。
- 编辑头像相机或模型后，会更新动画包围范围。这并非已确认能修复所有魔兽争霸 III 黑色头像的方案。

## 更新或下载
1. 打开 **Settings > Mouse**（设置 > 鼠标），更新按钮位于顶部。
2. 点击 **搜索更新**，再点 **更新并重启**。按提示保存修改，等待编辑器关闭并重启。安装过程中不要重新打开程序。
3. 如果更新失败或异常，请使用[完整下载](https://www.lowpolyworks.com/mdlxl/)。将整个 ZIP 解压到新文件夹，运行 **MDLxL.exe**，保留所有配套文件夹。请保留旧的个人配置和资源库，不要删除它们。
