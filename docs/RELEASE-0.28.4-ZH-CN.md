# MDLxL 0.28.4 - 热修复

**修复**

- Bones 模式在 Object 下拉列表下方、Multiselect 上方新增一行紧凑的 Bones / Helpers / Refs 复选框。重新打开编辑器后会保留可见性选择。
- Refs 现在可以再次选择、移动和编辑。Create > Ref 会创建参考附着点并立即显示。在 VIS 中，Bones、Helpers 和 Refs 始终启用，复选框行保持隐藏。
- Bones 保持绿色，Helpers 为紫色，Refs 为粉色。每个 Appearance 预设都有自己的颜色。白色背景上的文字采用深绿色、紫色和粉色，并带有细黑色描边以提高可读性。文字颜色可在 Appearance > Lists & folders 中调整，3D 标记颜色可在 Bones & skeleton 中调整。下拉菜单保持原有外观，Object 列表使用小黑色箭头。

**更新**  打开 Settings > Configuration > Search for updates > Update and restart，或从 MDLxL 页面下载完整便携版 ZIP。
