# MDLxL 0.32.1 - Vuelve el botón de huesos

- **Editor de huesos**: la fila superior vuelve a tener sus botones **Bones** y **Attachment**. Después de **Clear**, haz clic en **Bones** para volver a mostrar y seleccionar los huesos (la casilla Bones del panel Object lo sigue).

**Actualizar** Abre Ajustes > Configuración > Buscar actualizaciones > Actualizar y reiniciar, o descarga el ZIP portátil completo desde la página de MDLxL.
