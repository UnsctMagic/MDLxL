# MDLxL 0.40.2

- Lo sentimos: la 0.40.1 decía que los colores de Vértices estaban corregidos, pero con el suavizado de bordes activado seguían sin coincidir con Animaciones. Esta actualización lo corrige.
- Vértices: los colores de las geosets (RGB) y las capas transparentes se ven igual que en Animaciones con el suavizado de bordes activado. Antes, los rojos se veían anaranjados y desvaídos.

## 0.40.1

- Vértices: se abre con RGB activado, así que los colores de las geosets coinciden con Animaciones, Huesos y Movimiento.
- Vértices y Animaciones: las capas Aditivo se desvanecen con su alfa; cada textura conserva su propio ajuste de repetición (Wrap Width y Wrap Height), como en el juego.
- Animaciones: el interruptor Sombras funciona.
- Gestor de texturas: Agrupar texturas guarda los archivos de textura del modelo en un ZIP.
- Editor UV: Proyección de caja, Proyección cilíndrica, Enderezar, Copia reflejada, Desplegar y Relajar. Los controles de mapa y textura están en la barra de título; los avisos flotan sobre el mapa UV.
- MDLxL empieza con el espacio de trabajo vacío en lugar de un modelo sin título.
- Los botones se iluminan cuando un clic edita el modelo. Los controles que no pueden actuar se ocultan o se atenúan. Deshacer funciona en el gestor de Exhibición.
- OptimizeXL elimina pequeños giros lineales que mueven la malla como mucho un 0,25 %.
- Consola de IA: Claude Code usa el inicio de sesión de Claude Code de este PC.

Actualiza en Ajustes > Configuración > Buscar actualizaciones, o con el ZIP portátil.
