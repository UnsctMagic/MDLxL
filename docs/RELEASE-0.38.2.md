# MDLxL 0.38.2 — Hotfix

- The portable download now keeps the permanent filename `MDLxL-win32-x64.zip`. The same latest-download link will serve future releases. This release replaces the withdrawn 0.38.1 hotfix.
- Editor menus and panels respond more smoothly while recovery saves run. Recovery keeps full undo history and completed paint strokes, including when closing.
- Switching model tabs or changing Showcase quality no longer retains old previews and camera listeners. Shared texture lookups avoid repeated work and still notice changed files.
- UV Wrapper drags update live with less work. Rotate follows straight and circular mouse movement without resistance, keeps each piece on its own spot or several around their shared centre, and supports Shift for fine control. FX texture fitting and 3D rotation settings keep their existing controls.
- UV Wrapper Zoom restores its earlier collapse behaviour. Preview changes keep the camera and avoid unnecessary grid redraws; the Wrapper layout stays isolated from FX texture fitting.
- OptimizeXL keeps playing or paused while browsing findings and fix previews. Unused trailing pivot points can be repaired through Preview fix, selected repairs or Fix everything; returning with Back keeps the combined preview working.
- Small MDL/MDX file icons have clearer labels. Select through is remembered between starts.
- French and German are available across the interface and diagnostics. New release posts use English, Spanish, Russian, Simplified Chinese, French and German; existing release posts and historical PDF guides remain unchanged.
- Settings explains that game asset preloading is optional and uses disk space.

Update through Settings > Configuration > Search for updates > Update and restart, or download the full portable ZIP from the MDLxL page.
