# MDLxL 0.18.5 — Запись частиц в Showcase

- Showcase сохраняет время симуляции частиц на запрошенном кадре при считывании и кодировании GIF. Медленная обработка кадров больше не переводит часы эффектов вперёд с последующим откатом и удалением живых частиц.
- Существующие настройки времени предпросмотра и записи, размеры GIF, FPS, длительность, палитра и ограничение размера локального файла сохранены.
- Список звуков событий больше не предлагает отсутствующие определения звуков. Существующие узлы событий сохраняют свои идентификаторы до выбора корректной замены.

Скачайте **MDLxL-0.18.5-win32-x64.zip**, распакуйте весь ZIP и запустите **MDLxL.exe**. Все папки должны оставаться вместе. Архив соответствующего исходного кода FFmpeg доступен отдельно на странице релиза.
