# MDLxL 0.30.0 - Mejoras de Paint y la selección UV

- Citadel Paint: mantén Mayús y haz clic en **Desde archivo…** para importar una imagen copiada en la herramienta de recorte existente. Un clic normal sigue abriendo el selector de archivos. Ctrl+V y el editor de vértices no cambian.
- UV Wrapper: Live Select ahora incluye **Grabthrough**, activado de forma predeterminada. Desactívalo para seleccionar y mostrar solo los vértices visibles desde la cámara. Mantener A funciona después de hacer clic en Grabthrough o Highlight Live.
- UV Wrapper: N y la visualización rápida ya no pueden activar las normales por accidente mientras el editor UV está abierto. Las normales ya activadas se pueden desactivar, y los atajos mantienen el foco del teclado en el editor UV.
- NormalsXL: **Corregir orientación** orienta hacia fuera los puños, bandas y mangas invertidos. Otras piezas abiertas, como capas y calcomanías, permanecen intactas. Al recalcular las normales se conservan los triángulos propios de cada vértice y se usa el ángulo de suavizado para combinar vértices coincidentes, mejorando el sombreado de las esquinas.
- Las advertencias del editor parpadean en rojo una vez y conservan el texto rojo y un punto rojo mientras se muestran. Las advertencias repetidas vuelven a parpadear. Los mensajes normales conservan su aspecto.

**Actualizar** Abre Ajustes > Configuración > Buscar actualizaciones > Actualizar y reiniciar, o descarga el ZIP portátil completo desde la página de MDLxL.
