# MDLxL 0.39.0

- **城堡漆：** **新建底色**采用新布局，部件整齐端正，接缝大幅减少，头部默认获得更多像素。**细节**可设置所选部件获得多少像素。还新增压感、平滑、对称（V）、Alt 导航、Ctrl + 右键拖动调整笔刷大小和柔和度、图层不透明度和 1024 底色。
- **计算边界**现在在模型检查器、OptimizeXL 和 Save As 中使用同一计算方式。它会排除头像背景、英雄和队伍辉光以及叠加效果网格，使血条位于正确高度。
- **EMTR 和英雄辉光**现在具有主编辑器在 X、Y、Z 轴上的旋转控制柄。**添加丝带**可生成游戏原生风格的武器拖尾，只在挥动时显示。丝带字段会实时更新拖尾，叠加丝带也会跟随亮度变化。
- **节点管理器：**可在当前帧显示、隐藏和移除发射器的可见性关键帧。
- **FX：**选择粒子发射器时会先预览，点击**添加**才会保留。库的常规文件夹中新增十种外观。
- **OptimizeXL：**Insanity FIxer 中的**移除完全冗余**可移除重复的结尾关键帧、恒定轨道和塌陷三角形，且不改变模型外观。备用姿态动画现在只与自身姿态比较。
- **骨骼标签：** **摆动**（J）会在预览中摆动所选骨骼，绑定错误的部件能立刻看出来。模型不会被更改。
- **建模：**使用调整大小时按住 Ctrl，可让部件靠拢或分开而保持原大小。右键点击**解除耦合**并关闭**炸开**，可分离顶点而不移动它们。
- **UV 编辑器：**材质下拉列表显示模型中的所有材质。旋转和缩放遵循同一固定规则，大部件不再快过鼠标。
- **POSE 和 ANIM：**肘部和膝部的旋转与其他控制柄一致。在 ANIM 中拖动空白处可转动摄像机。
- **自动遗骸：**支持带翅膀、尾巴、超过 254 个节点和循环效果的大型遗骸。
- **AI 控制台：**你和 AI 对不同数据的编辑会自动合并为一次撤销。AI 审查不再使窗口卡住。
- **保存：**验证问题现在只是警告，绝不会阻止保存。边界已正确时，带计算边界的 Save As 也能正常保存。
- 每个帧区间都会显示总帧数，动画中的高亮多边形组可双向使用。

可通过 设置 > 配置 > 检查更新 > 更新并重启 进行更新，或从 MDLxL 页面下载完整便携版 ZIP。
