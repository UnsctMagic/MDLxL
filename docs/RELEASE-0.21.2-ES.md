# MDLxL 0.21.2 — Corrección para 0.21.1

Esta corrección se distribuye como un paquete portátil completo de MDLxL. Soluciona dos problemas del editor y conserva las rutas originales de las texturas y los datos de los modelos.

- EMTR conserva las rutas originales de las texturas de la biblioteca al insertar efectos nativos de Warcraft III. Ya no crea rutas nuevas para esas texturas.
- UV Wrapper mantiene visible la vista previa del modelo durante pequeños cambios de UV, también al previsualizar una textura de reemplazo.
- MDLxL 0.21.1 ofrece esta corrección al usar **Buscar actualizaciones** o si está activada la comprobación al iniciar. **Actualizar y reiniciar** descarga y verifica el ZIP completo de 0.21.2.
- Si tu instalación tiene el problema anterior del actualizador, descarga y extrae el paquete completo desde [Low Polyworks](https://www.lowpolyworks.com/mdlxl/).
