# MDLxL 0.29.2 - 热修复

根据大家的反馈，又修了三处。

**修复**

- OptimizeXL：“保存”提示不再被肖像边框切碎。整个对话框完整显示，后面的预览会变暗，提示和大小摘要也已完整翻译。
- 城堡漆：每个模型标签页保留自己的相机。切换到另一个模型再切回来，不再重置角度和缩放；编辑器视图也不再把上一个标签页的相机套用到下一个模型上。
- 文件 > 新建（以及关闭最后一个标签页）现在会创建真正的空模型，而不是初始立方体。

**更新**  打开 Settings > Configuration > Search for updates > Update and restart，或从 MDLxL 页面下载完整便携版 ZIP。
