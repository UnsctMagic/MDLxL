# MDLxL 0.32.1 - Кнопка костей вернулась

- **Редактор костей**: в верхнем ряду снова есть кнопки **Bones** и **Attachment**. После **Clear** нажмите **Bones**, чтобы снова показать и выбирать кости (флажок Bones в панели Object следует за ней).

**Обновление** Откройте Настройки > Конфигурация > Проверить обновления > Обновить и перезапустить или скачайте полный портативный ZIP со страницы MDLxL.
