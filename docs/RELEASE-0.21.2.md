# MDLxL 0.21.2 — Hotfix for 0.21.1

This hotfix is a complete portable MDLxL package. It corrects two editor issues without changing your authored texture paths or model data.

- EMTR keeps the library's original texture paths when inserting native effects. It no longer invents paths for those textures.
- UV Wrapper keeps the live model preview visible during small UV edits, including edits made while a replacement texture is being previewed.
- MDLxL 0.21.1 offers this hotfix when you use **Search for updates** or have startup checks enabled. **Update and restart** downloads and verifies the complete 0.21.2 ZIP.
- If you use an older installation affected by the previous updater problem, download and extract the complete package from [Low Polyworks](https://www.lowpolyworks.com/mdlxl/).
