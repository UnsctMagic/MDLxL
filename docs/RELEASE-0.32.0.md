# MDLxL 0.32.0 - AI works in the background

- **AI works in the background**: the AI keeps working on its own model while you open and edit other models. Its edits land in that model's tab as normal Undo steps; your Ctrl+Z on the tab you are using never touches them.
- **Several AI jobs at once**: each model's chat runs its own job. Send a prompt on one model, switch to another and send another. Stop and steering act on the chat you are looking at.
- AI: review pictures are drawn off-screen, so your view and camera never move while the AI looks at the model. Steps that need the screen (such as Save) wait until you return to that model's tab.
- AI: MDLxL now finds Codex and Claude Code on any Windows PC, including the copies inside their desktop apps, and recovers by itself when an update moves them.
- AI: a model you attach as a reference now shows as a chip in the message box. Click its **×** to remove it, like an attached picture (this closes its tab).
- AI: Ctrl+C copies text you select in the AI chat, and pasting text copied from Word or a web page pastes the text instead of a picture of it.
- AI: Pen, Marker and Eraser always show which tool the mouse is using. A middle-click to camera rotation puts the drawing tool away, and picking a drawing tool switches back so it really draws.

- **File icons**: Settings > Configuration > File icons now has separate rows for **MDL files** and **MDX files**, with five new labelled icons for each (blue MDL, red MDX). Your current icon stays until you change it.
- UV Wrapper now opens facing the front of the model and fits it in view.
- Quad View: the view toolbar no longer covers the pane labels.
- Dropdowns (language list, UV Triangles menu, keyframe and bone menus) now follow your theme instead of showing white in dark themes.
- Russian: the UV button now reads "UV-карты" (shorter, so it fits), and narrow-window display chips name themselves in their tooltip.

**Update** Open Settings > Configuration > Search for updates > Update and restart, or download the full portable ZIP from the MDLxL page.
