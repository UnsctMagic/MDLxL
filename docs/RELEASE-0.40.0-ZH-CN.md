# MDLxL 0.40.0

- 顶点：动画预览（Shift+空格）在编辑时让模型摆出动画姿势。每一块位于工作平面约束旁边，锻造中同样如此；在锻造中右键选择调用 Forge 工具即可使用其工具。
- 骨骼：骨骼命名设置 Blizzard 标准骨骼名称。
- POSE：控制柄依据形状、骨架、名称、动画和附着点生成；圆形、正方形或菱形；符号集、符号颜色和圆环颜色在设置中。右键 > 隐藏；POSE 旁的按钮可恢复。拖动控制柄在悬停时显示其作用。
- UV 编辑器：RGB 预览、隐藏多余项；全新安装默认向右或向上缩放。
- EMTR：右键可打开英雄辉光、EMTR 库或管理器。预览：选中的发射器或显示所有发射器。查看检测到的辉光会跳过单个部件。添加武器辉光可用于多把武器。添加丝带：扫掠（火焰、冰霜…）、播放速度。
- FX：统一的图层面板；添加图层和添加发射器可搜索；一次放置一个发射器（EMTR 控制柄）或点击表面放置；另存为…、加载自…、我的效果；重做的效果；暂停；重新调整保留贴图和 UV 修改。
- 对象：骨骼和运动中只有一个对象开关（右键：类型）和灯光，顶点中没有。在运动中点击对象，关键帧轨道上显示 EMTR 的菱形；双击发射器符号打开 EMTR。VIS 与 MDLVis 1.40 一致。
- LIBR：右键可打开纹理、模型、声音或全部。所有查看器均可另存副本…。世界编辑器样式中每个对象只列出一次。
- BITZ：管理文件和文件夹。替换部件：四视图、RGB、取消、应用。
- 菜单：管理器是顶部菜单。菜单显示快捷键；Alt+K：表面特效。
- 声音：五个位置变动的游戏声音可以播放；缺失的显示游戏中没有该声音文件。
- 对象管理器（原节点管理器）：新建列出游戏中的声音、溅射和可用的生成对象，并可预览；添加事件添加一项。
- 视图：顶点、骨骼、运动和动画中的坐标轴参考线；运动和骨骼中的紧凑集按行排列。ShareX 区域（设置 > 录制）用于视口或工具箱。
- AI 控制台：模型原有的错误显示为警告；新增错误会阻止。
- 修复：删除和合并后 FX 保留其部件。无法读回的保存会保留旧文件。动画预览中移动顶点会跟随鼠标。绘画中拖动画笔更流畅，Esc 可恢复。BITZ 关闭未完成的替换前会提示。切换发射器时 EMTR 保留预览；组件显示粒子和丝带。纹理视图按游戏方式显示调制和 2 倍调制。
- 德语和法语键盘：0.39 之前重新绑定的字母快捷键可能已移位。

更新：设置 > 配置 > 检查更新，或使用便携版 ZIP。
