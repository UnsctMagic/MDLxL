# MDLxL 0.40.0

- **顶点：** **动画预览**（Shift+空格）在编辑基础姿势时显示动画的定格姿势。用箭头选择动画序列，或右键单击此按钮来选择帧。“移动”编辑器的播放位置保持独立。
- **视图：** 顶点、骨骼、移动和动画编辑器均可显示坐标轴辅助线。
- **UV 编辑器：** **RGB 预览**仅在预览中为当前几何组着色。**隐藏 Extras**会保留正在编辑的几何组，同时隐藏其他特效。预览采用模型未播放动画时的外观。全新安装默认使用向右或向上拖动缩放，现有配置保留原设置。
- **EMTR：** 默认只预览选中的发射器，选择**显示所有发射器**可查看其余发射器。**英雄辉光** 能区分英雄光效和较小的眼部特效。使用**查看检测到的辉光**时，可以逐个排除或恢复光效部件。
- **FX：** 重新调整已应用的特效会保留贴图和 UV 修改。FX 和 EMTR 中的贴图库采用常规外观，世界编辑器样式下每个对象只列出一次。
- **骨骼绑定编辑器：** **紧凑集** 按行排列几何组。
- **AI 控制台：** 审查会提示初始模型已有的错误，仍会阻止新增的错误。

在设置中检查更新，或下载完整的便携版 ZIP。
