# MDLxL 0.40.0

- **顶点：****动画预览**（Shift+空格）在编辑时显示动画姿势。**每一块**位于**工作平面约束**旁边，锻造中同样如此。
- **锻造：**右键选择**调用 Forge 工具**，即可在顶点编辑器中使用其工具。
- **骨骼：****骨骼命名**为骨架设置 Blizzard 标准骨骼名称。
- **POSE：**主控制柄可选**圆形**、**正方形**或**菱形**。拖动控制柄在悬停时显示其作用（移动、拉伸…）。
- **UV 编辑器：**未播放动画的预览中新增 **RGB 预览**和 **隐藏多余项**。全新安装默认向右或向上缩放。
- **EMTR：**右键可打开**英雄辉光**、**EMTR 库**或**管理器**。预览显示选中的发射器，**显示所有发射器**显示全部。**查看检测到的辉光**可排除单个辉光部件。
- **FX：**放置预览下方新增**暂停**。重新调整会保留贴图和 UV 修改。
- **LIBR：**右键可打开**纹理**、**模型**、**声音**或**全部**。所有查看器均可**另存副本…**（DDS、BLP、PNG）。**世界编辑器样式**中每个对象只列出一次。
- **BITZ：****管理** Bitz 文件和文件夹。**替换部件**会打开四视图，并提供 RGB、**取消**和**应用**。
- **菜单：**管理器选项卡已移入顶部**管理器**菜单。菜单显示快捷键，Alt+K 打开**表面特效**。
- **声音：**五个位置变动的游戏声音现在可以播放。游戏中没有文件的声音标记为**游戏中没有该声音文件**。
- **视图：**顶点、骨骼、运动和动画编辑器中新增**坐标轴参考线**。运动和骨骼中的**紧凑集**同样按行排列。
- **ShareX 区域**（设置 > 录制）让 ShareX 只截取视口或工具箱。
- **AI 控制台：**模型原有的错误显示为警告，新增错误仍会阻止。
- **修复：**删除和合并后 FX 保留其部件。无法读回的保存会保留被替换文件的副本。在快捷键中选择“默认”前会先确认。动画预览中移动顶点会跟随鼠标。绘画中拖动画笔更流畅，Esc 可恢复数值。关闭未完成的替换前，BITZ 会提示。切换发射器时 EMTR 保留预览；**组件**中的图片重新显示粒子和丝带。
- 使用德语或法语键盘时，在 0.39 版之前重新绑定的字母快捷键现在可能对应其他按键。请在“设置 → 快捷键”中检查。

可通过 设置 > 配置 > 检查更新 > 更新并重启 进行更新，或从 MDLxL 页面下载完整便携版 ZIP。
