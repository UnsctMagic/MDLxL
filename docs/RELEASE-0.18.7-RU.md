# MDLxL 0.18.7 — Стабильное перемещение вершин и исходные текстуры Bitz

- Геосеты с билбордами и ориентацией на камеру теперь остаются под указателем при перемещении вершин в обычном и четырёхоконном режиме. После отпускания кнопки видимое положение сохраняется, а отмена точно восстанавливает исходные координаты.
- «Собрать Bit» и импорт целой детали сохраняют исходное имя файла, относительный путь и байты каждой текстуры вместо замены пути хешированным путём MDLxL или преобразования обычных изображений в TGA. При совпадении имён существующие файлы не перезаписываются.
- Полосу времени анимации можно прокручивать ниже области ключевых кадров; привязка к ближайшим ключам сохраняется.
- Прежний профиль записи Showcase «Hive» теперь называется «Low Size».

Скачайте **MDLxL-0.18.7-win32-x64.zip**, распакуйте весь ZIP и запустите **MDLxL.exe**. Все папки должны оставаться вместе. Архив соответствующего исходного кода FFmpeg доступен отдельно на странице релиза.
