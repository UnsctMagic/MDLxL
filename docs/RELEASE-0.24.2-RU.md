# MDLxL 0.24.2 - Restrict включён по умолчанию, быстрые привязки и надёжное сохранение MDL

## POSE

- Restrict теперь включён по умолчанию: при перемещении руки или ноги тело остаётся на месте. Нажмите Restrict, чтобы выключить его, и конечность снова будет вести за собой тело.

## Движение

- Показ привязок (Привязка) больше не замедляет вид XL. Модели с большим числом привязок воспроизводятся почти так же плавно, как с выключенной Привязкой.

## Сохранение

- При сохранении в MDL теперь сохраняются редкие значения, которые раньше терялись: необычные режимы фильтра материала, дополнительные флаги анимации геосетов и белый цвет ленточных эмиттеров. Повторно открытый MDL даёт ту же модель.

## Обновление

В 0.24.1 откройте Настройки > Конфигурация > Проверить обновления > Обновить и перезапустить.
