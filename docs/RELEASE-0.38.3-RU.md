# MDLxL 0.38.3

- **Важное исправление OptimizeXL:** модели, сохранённые после OptimizeXL, могли повреждаться и показывать в Warcraft III длинные вытянутые шипы, хотя в MDLxL выглядели нормально. То же могло случиться после первого добавления в модель форм столкновения, лент или точек крепления. Теперь MDLxL сохраняет каждую модель в том порядке, в котором её читает игра. Модель, уже сохранённая таким образом, исправляется при следующем изменении и сохранении.
- Восстановление продолжает сохранять данные после выхода из Citadel Paint посреди мазка, при постоянных щелчках в большой модели и во время закрытия MDLxL.
- Консоль ИИ: **Local workspace** позволяет ИИ выполнять собственные проверки и хранить временные файлы для задачи, предварительно спросив вас карточкой «Да/Нет». Если вы меняете модель во время работы ИИ, выберите **Open as new model** или **Merge**; объединение отменяется одним Undo.
- Испанский, русский и китайский теперь переводят все замечания проверки Hive.
- Версии старше 0.38.0 снова могут обновляться из программы.
- Shredder в окне обновления остаётся скрытым за краем, из-за которого выглядывает.

Обновление: Settings > Configuration > Search for updates > Update and restart. Также можно скачать полный переносимый ZIP на странице MDLxL.
