# MDLxL 0.40.1

- 顶点：打开时 RGB 已开启，几何体颜色与动画、骨骼和运动一致。
- 顶点和动画：叠加图层随其透明度淡出；每个纹理保留自己的平铺设置（Wrap Width 和 Wrap Height），与游戏一致。
- 动画：阴影开关可以正常使用。
- 纹理管理器：“打包纹理”将模型的纹理文件保存到一个 ZIP 中。
- UV 编辑器：盒体投影、圆柱投影、拉直、镜像复制、展开和松弛。贴图和纹理控件位于标题栏；警告浮动显示在 UV 贴图上方。
- MDLxL 启动时为空工作区，不再创建未命名模型。
- 点击修改模型时按钮会亮起。无法操作的控件会隐藏或变灰。展示管理器中的撤销可以使用。
- OptimizeXL 移除使网格移动不超过 0.25% 的小幅线性旋转。
- AI 控制台：Claude Code 使用本机自己的 Claude Code 登录。

更新：设置 > 配置 > 检查更新，或使用便携版 ZIP。
