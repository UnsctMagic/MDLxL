# MDLxL 0.18.6 — Вкладки геосетов и поиск по размеру

- Менеджер геосетов теперь сохраняет рабочие вкладки. Открывайте, переключайте, переименовывайте, закрывайте вкладки и добавляйте геосет во вкладку правым щелчком, не теряя текущий контекст редактирования.
- В редакторах вершин и движения выбранные геосеты можно оставить видимыми для контекста, скрыв их маркеры вершин. Геосеты остаются понятными, но не становятся редактируемым выделением.
- В компактном интерфейсе VIS элементы управления отображением остаются доступны.
- Поиск в Библиотеке текстур принимает запросы размера в пикселях и разрешения: например, `512`, `512x512` и `1024x512`.

Скачайте **MDLxL-0.18.6-win32-x64.zip**, распакуйте весь ZIP и запустите **MDLxL.exe**. Все папки должны оставаться вместе. Архив соответствующего исходного кода FFmpeg доступен отдельно на странице релиза.
