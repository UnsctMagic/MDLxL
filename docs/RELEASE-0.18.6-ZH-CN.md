# MDLxL 0.18.6 — 几何体标签页与尺寸搜索

- 几何体管理器现在会保留工作标签页。你可以打开、切换、重命名、关闭标签页，并通过右键将几何体放入标签页，而不会丢失当前编辑上下文。
- 顶点和动作编辑器可让选中的几何体保持可见以提供上下文，同时隐藏其顶点标记。这样几何体仍清晰可见，但不会变成可编辑的选择。
- VIS 的紧凑布局中仍可使用显示控制。
- 纹理库搜索支持像素尺寸和分辨率查询，例如 `512`、`512x512` 和 `1024x512`。

下载 **MDLxL-0.18.6-win32-x64.zip**，解压整个 ZIP，然后运行 **MDLxL.exe**。请将所有文件夹放在一起。FFmpeg 对应源代码压缩包可在发布页面单独下载。
