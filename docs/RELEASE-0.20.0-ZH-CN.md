# MDLxL 0.20.0 — 更新、恢复上一版本与翻译

MDLxL 现在可以检查下一次发布。本版本还包含 0.19.0 中已发布的全部 Forge、SHAPE 和编辑器改进。

- **更新：** 设置 → 鼠标中新增了 **检查更新** 和 **自动更新**。自动更新默认关闭。开启后，程序在启动时检查一次，并在发现较新的稳定版本时提示您。只有选择 **更新并重启** 后才会下载和安装。
- **查看更改：** 更新提示用您的语言显示简短的更改列表。完整日志发布在 [Low Polyworks](https://www.lowpolyworks.com/mdlxl/?version=0.20.0&lang=zh)，顶部可选择英语、俄语、西班牙语或简体中文。
- **恢复上一版本：** 每次成功更新都会保留且仅保留一个上一程序版本。可以在设置中离线恢复。下一次成功更新会替换这份副本。更新和恢复时，当前设置、个人库、录制内容和已保存文件都会保留。重启前，MDLxL 会询问如何处理未保存的工作。
- **翻译：** 新增控件、提示、编辑器消息和更新窗口现在提供俄语、西班牙语和中文翻译。已有的社区翻译保持原样。
- **官方网站：** 帮助、关于和更新提示中加入了小型 Low Polyworks 链接。请从 [MDLxL 官方页面](https://www.lowpolyworks.com/mdlxl)开始下载。

## 同时包含 0.19.0 的改进

- **Forge 与 SHAPE：** 可视化基础形状、尺寸、厚度、适中的复杂度和 ThumperXL 头盔；Projector 纹理与裁切；Curve、Fold、Twist、Dome、Roll 和 Taper 的预览流程，并为粗略几何自动增加支撑行。
- **BITZ 与 EMTR：** 在 Quad View 中放置部件并保留骨骼绑定，收集每个动画的 RGB 调色板，整理模型文件夹；独立的库效果工作副本，分离冲突的纹理路径。
- **材质与 UV：** 可撤销的 Sort My Mess 合并及前后对比预览；临时 UV 纹理允许正常编辑几何，保留原有材质设置，恢复纹理时保留几何与 UV 更改；更快的初始 UV 滚动，背景不再叠加队伍颜色。
- **编辑器与录制：** 可调整高度的地理集列表；Animations 显示粒子与飘带且不显示编辑标记；GIF 临时帧保存在录制目标磁盘上。

## 获取本版本

打开 [www.lowpolyworks.com/mdlxl](https://www.lowpolyworks.com/mdlxl)，下载 Windows 便携版 ZIP，完整解压文件夹并运行 **MDLxL.exe**。请将程序文件夹保持在一起。没有更新功能的旧版本需先下载本便携版；之后可在设置中安装更新。页面还提供 FFmpeg 对应源代码归档的链接。
