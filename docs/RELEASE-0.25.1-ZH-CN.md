# MDLxL 0.25.1 - 修复：Shift 平面锁定

## 顶点

- 关闭工作平面时，拖动中按住 Shift 现在会把移动锁定在所选的 XY、ZX 或 YZ 平面内，与 MDLVis 一致。以前在倾斜的相机角度下，选中内容可能会离开该平面。
- 按住 Shift 拖动时，或在拖动途中按下或松开 Shift 时，被拖动的顶点不再跳动，而是从当前位置继续移动。
- 同样的修复也适用于在顶点视图中拖动骨骼、绘画模式，以及运动模式中的自由节点拖动和 POSE 拖动。
- Quad View 保留自己的 Shift 锁定：按住 Shift 并向侧面或向上移动即可锁定该方向。

## 更新

在 0.25.0 中，打开设置 > Configuration > 检查更新 > 更新并重启。
