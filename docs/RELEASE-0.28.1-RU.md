# MDLxL 0.28.1 - Срочное исправление

## Исправления

- UV Wrapper: жёлтое предупреждение о текстуре больше не мигает, а рабочая область больше не прыгает, пока карта текстуры перерисовывается после смены материала. Сильнее всего это было заметно на медленных ПК.
- Библиотека частиц: все 34 проверенных названия эффектов вернулись (например, «Low black smoke» и «Narrow flame column»). 11 из них снова показывали автоматические названия. Теперь проверенные названия остаются у своего эффекта после пересборки библиотеки и обновлений Warcraft III, если модель в игре не изменилась.
- Сообщение о порождаемых эффектах, которые нельзя просмотреть, снова переведено на испанский, русский и китайский для всех форматов моделей, включая 1800.
- Кузница: добавление выкованной детали больше не меняет сохранённые границы других геосетов модели.

## Обновление

В 0.28.0 откройте «Настройки > Конфигурация > Проверить обновления > Обновить и перезапустить».
