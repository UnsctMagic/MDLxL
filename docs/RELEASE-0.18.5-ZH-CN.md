# MDLxL 0.18.5 — Showcase 粒子录制

- Showcase 在读取和编码 GIF 时，将粒子模拟时间保持在请求的导出帧。较慢的帧处理不会再使效果时钟先前进再回退，从而清除仍然存活的粒子。
- 保留现有预览和录制时间设置，以及 GIF 尺寸、FPS、时长、调色板和本地文件大小限制。
- 事件声音选择列表不再显示无法解析的声音定义。现有事件节点会保留其 ID，直到用户选择有效的替代项。

下载 **MDLxL-0.18.5-win32-x64.zip**，解压整个 ZIP，然后运行 **MDLxL.exe**。请将所有文件夹放在一起。FFmpeg 对应源代码压缩包可在发布页面单独下载。
