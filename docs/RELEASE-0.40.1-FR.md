# MDLxL 0.40.1

- Sommets : s'ouvre avec RGB activé, donc les couleurs des geosets correspondent à Animations, Os et Mouvement.
- Sommets et Animations : les calques Additif s'estompent avec leur alpha ; chaque texture garde sa propre répétition (Wrap Width et Wrap Height), comme dans le jeu.
- Animations : l'interrupteur Ombres fonctionne.
- Gestionnaire de textures : Regrouper les textures enregistre les fichiers de texture du modèle dans un ZIP.
- Éditeur UV : Projection en boîte, Projection cylindrique, Redresser, Copie miroir, Déplier et Détendre. Les contrôles de carte et de texture sont dans la barre de titre ; les avertissements flottent au-dessus de la carte UV.
- MDLxL démarre avec un espace de travail vide au lieu d'un modèle sans titre.
- Les boutons s'allument quand un clic modifie le modèle. Les contrôles qui ne peuvent pas agir sont masqués ou grisés. Annuler fonctionne dans le gestionnaire Showcase.
- OptimizeXL supprime les petites rotations linéaires qui déplacent le maillage d'au plus 0,25 %.
- Console IA : Claude Code utilise la connexion Claude Code de ce PC.

Mettez à jour via Réglages > Configuration > Rechercher des mises à jour, ou avec le ZIP portable.
