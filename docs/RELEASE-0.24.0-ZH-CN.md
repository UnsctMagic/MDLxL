# MDLxL 0.24.0 - HD 模型与保存修复

## HD 模型

- 带有 HD 纹理或蒙皮权重的 Reforged HD 模型会以仅查看模式打开，并弹出提示：暂不支持 HD 模型。保存已禁用，状态栏和 帮助 > Model diagnostics 中也会显示同样的说明。
- 仅包含 HD 着色器名称或 HD 光照数值的模型会询问：以仅查看模式打开，还是转换为 SD。转换会移除这些设置；保存之前文件不会改变。
- 粘贴到 SD 模型或从粒子预设放置的 HD 内容会转换为 SD，并弹出提示。在材质检查器中输入的着色器名称不会被应用。
- HD 事件资源和 HD BitsAndParts 部件会显示同样清晰的提示，而不是直接失败。1300–1800 格式的事件预览会提示需要兼容的 Warcraft 渲染器。

## 保存

- 当经典粒子发射器（ParticleEmitter）带有可见性时，保存为 MDL 不再卡死。
- 以前被错误拒绝的保存现在可以完成：删除了全部三角形的几何组、环境光颜色为白色的光源，以及辅助对象带有其他工具遗留骨骼标记的模型。

## 更新与翻译

- 当 Windows 账户的临时文件夹使用带“~1”的短路径时（常见于较长或非拉丁字符的用户名），应用内更新现在可以正常安装。
- Forge 快捷键名称、事件显示开关以及新的 HD 提示已翻译为俄语、西班牙语和中文。

## 内部改进

- 编辑器主代码已拆分为更小、更专一的文件，并删除了未使用的代码和重复的辅助函数。
- 翻译现在每种语言一个文件，所有现有译文均保持不变。
- 每次更改现在都会运行约 1600 项自动测试；前后对比确认模型的打开、保存和显示与 0.23.0 完全相同。
- MDLxL 的行为没有变化。

## 更新

在 0.23.0 中，打开设置 > Configuration > 检查更新 > 更新并重启。如果在临时文件夹为“~1”短路径的账户中无法安装更新，请从 [Low Polyworks](https://www.lowpolyworks.com/mdlxl) 下载一次完整的 Windows 便携 ZIP，解压整个文件夹并运行 MDLxL.exe。之后的更新可在应用内完成。
