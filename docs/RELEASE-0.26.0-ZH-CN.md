# MDLxL 0.26.0 - 重做 NormalsXL，修复 MDL 保存

## NormalsXL

- NormalsXL 现在按 Retera's Model Studio 的方式重新计算法线。它从不添加或删除顶点，因此文件大小保持不变。
- 法线只根据三角形重建，因此整片错误、翻转或为空的法线一键即可修正。纹理接缝会被平滑，模型中已经分开的边保持锐利。
- 不同骨骼上的部件和可替换部件不会互相平滑。
- 面板更简单：一个平滑角度滑块（默认 90°）、显示法线、应用和取消。
- 打开 NormalsXL 时立即显示法线：黄色线是它会更改的法线，蓝色线保持不变。
- 修正朝向是单独的按钮和单独的撤销步骤。它会翻转朝向错误的三角形（包括成片的三角形）以及里外翻转的封闭部件，从不添加顶点。
- 选中顶点时，只更改选中区域。

## 保存

- 带有未启用着色的几何体颜色或 MDLVis 编辑器数据的模型，现在可以保存为 MDL。游戏不会使用这两者，因此 MDL 会省略它们，并在状态栏中说明。MDX 仍会保留它们。

## 更新

在 0.25.1 中，打开设置 > Configuration > 检查更新 > 更新并重启。
