# MDLxL 0.40.3

- XFER 很难做到完全正确，因此仍在开发中：请检查每个结果，有些模型仍需手动修正。
- ANIM 暂时移除，只有在真正有用时才会回来。
- XFER（转移，F11）：把另一个模型的动作给当前模型。“移植”把模型放到另一个模型的骨架上并带上它的全部动画；“重定向”按身体部位逐个获取动作。“旋转”“位置”或“混合”决定四肢如何跟随。详见 XFER 指南（PDF）。
- 每个滑块都有小的 − 和 +，每次移动一步。
- 顶点编辑器：新的“切割”工具（I 键）在三角形的一条边上加一个新点并分割三角形。
- UV 编辑器：“适应”把选中的 UV 移进你在纹理上标出的区域。“替换纹理…”位于材质行的末尾。“RGB 预览”重新显示整个模型的 RGB。
- 运动：“运动轨迹”画出选中骨骼的路径（颜色在 设置 > 外观 > 编辑器辅助）。“局部坐标轴”让旋转手柄随选中的骨骼转动。事件显示其声音、血迹或生成名称；双击事件帧即可在动画中查看。
- 顶视图和底视图绕模型的竖直轴旋转，不再把模型翻倒。
- 播放中的动画在你编辑时暂停，编辑完成后继续播放。
- 编辑面板有隐藏按钮。窄视图中的相机栏显示为图标。
- FX：快速视图在模型打开期间保留外观，大模型上 FX 打开更快。FX 和 EMTR 将图片保存为 .blp。
- EMTR：切换发射器不再重播效果。PRE2 发射区域在预览中朝向正确。
- OptimizeXL：“计算边界”提供“完全”或“仅必要”（文件更小）。“未使用数据”保持 FX 层一致。“重新排序”可用于几何体边界表较短的模型。
- 帮助 > 报告问题… 直接把简短的纯文本报告发给我。
- AI：工作不再中途停下，“查看 AI 工作”在编辑器中重播 AI 的每一步，更多 AI 提供方（先 Claude，后 Codex），并可在 UV 编辑器和运动中画笔记。
- 节点管理器：声音搜索能找到所有资料片的声音。

更新：设置 > 配置 > 检查更新，或使用便携版 ZIP。
