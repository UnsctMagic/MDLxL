# MDLxL 0.29.1 - Hotfix

Too annoying to not fix.

**Fixes**

- Material & Texture Library: a texture that is already in the model takes one click again. Preview Texture in Editor or Add opens a small popup with one button per material that already shows the texture (for example Material 12 · geoset 18) and New material. One click picks and finishes; Escape closes only the popup. The dropdown and extra buttons in the details column are gone.

**Update**  Open Settings > Configuration > Search for updates > Update and restart, or download the full portable ZIP from the MDLxL page.
