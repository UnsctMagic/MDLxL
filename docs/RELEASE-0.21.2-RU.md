# MDLxL 0.21.2 — Исправление для 0.21.1

Это полный переносимый пакет MDLxL. Обновление устраняет две проблемы редактора и сохраняет исходные пути текстур и данные моделей.

- EMTR сохраняет исходные пути текстур из библиотеки при добавлении стандартных эффектов Warcraft III и больше не создаёт для них новые пути.
- UV Wrapper оставляет предварительный просмотр модели видимым при небольших изменениях UV, в том числе во время предварительного просмотра заменяемой текстуры.
- В MDLxL 0.21.1 это обновление предлагается после команды **Поиск обновлений** или при включённой проверке при запуске. Команда **Обновить и перезапустить** загружает и проверяет полный ZIP-пакет 0.21.2.
- Если установленная версия затронута прежней ошибкой обновления, скачайте и распакуйте полный пакет с [Low Polyworks](https://www.lowpolyworks.com/mdlxl/).
