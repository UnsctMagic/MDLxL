# MDLxL 0.18.7 — Stable vertex dragging and original Bitz textures

- Billboard and camera-facing geosets now stay under the pointer while moving vertices in normal and Quad View. Releasing the drag preserves the visible position and undo restores the exact authored coordinates.
- Collect Bit and Import whole part preserve each source texture's original filename, relative path, and bytes instead of replacing it with a hashed MDLxL path or converting ordinary images to TGA. Existing files remain protected on collisions.
- The animation timeline can be scrubbed below the keyframe box while retaining nearby-key snapping.
- Showcase's former Hive recording profile is now named Low Size.

Download **MDLxL-0.18.7-win32-x64.zip**, extract the whole ZIP, and run **MDLxL.exe**. Keep its folders together. The FFmpeg corresponding source archive is provided separately for redistribution.
