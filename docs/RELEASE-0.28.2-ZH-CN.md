# MDLxL 0.28.2 - 标记性能与编辑修复

## 更新内容

- 绘制骨骼、骨架连线和附着点标记所需的 CPU 时间减少。原有图标、颜色、大小、选中高亮和鼠标操作保持不变。在本地使用 Blood Dragon Nightmare 模型测试时，这些标记的合计处理时间从 23.8 毫秒降至 6.7 毫秒。这是标记处理时间，并非整帧耗时；实际效果取决于电脑配置。无需修改模型。
- 收集的 Bits 在保存或再次使用时会保留自身材质。看似相同但引用不同纹理的材质不再替换部件原有材质，避免保存后出现部件缺失或显示错误。
- 现在可以焊接尚未组成三角形的独立顶点：先合并点，再创建面。对于已有网格，防止焊接操作删除全部三角形的保护仍然有效。
- 更新了项目贡献者和技术来源说明，并保留 MDLxL 所用库与资源的相关声明。

本版本包含 0.28.1 之后合并的全部更改：贡献者说明（#248）、独立顶点焊接（#249）、收集的 Bits 材质（#250）和标记渲染（#251）。

## 更新方法

打开 Settings > Configuration > Search for updates > Update and restart，或从 MDLxL 页面下载完整的便携版 ZIP。
