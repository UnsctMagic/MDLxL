# MDLxL 0.32.0 - AI 在后台工作

- **AI 在后台工作**：在你打开和编辑其他模型时，AI 会继续处理它自己的模型。它的修改作为普通的撤销步骤进入该模型的标签页；你在当前标签页按 Ctrl+Z 永远不会动到它们。
- **同时运行多个 AI 任务**：每个模型的聊天各自运行一个任务。在一个模型上发送提示，切换到另一个模型再发送一个。停止和引导只作用于你正在查看的聊天。
- AI：检查用的图片在屏幕外绘制，所以 AI 查看模型时你的视图和相机不会移动。需要屏幕的步骤（例如保存）会等你回到该模型的标签页。
- AI：MDLxL 现在能在任何 Windows 电脑上找到 Codex 和 Claude Code，包括它们桌面应用内的副本；更新移动了它们的位置时也会自动恢复。
- AI：Pen、Marker 和橡皮擦始终显示鼠标正在使用哪个工具。中键切换到相机旋转会收起绘图工具；选择绘图工具会切回工作模式，确保它真的在绘制。

- **文件图标**：设置 > 配置 > File icons 现在分为 **MDL files** 和 **MDX files** 两行，每种格式各有五个带标签的新图标（蓝色 MDL，红色 MDX）。在你更改之前，当前图标保持不变。
- UV 编辑器现在打开时正对模型正面，并让模型完整显示在视图中。
- 四视图：视图工具栏不再遮挡各窗格的名称。
- 下拉菜单（语言列表、UV 的 Triangles 菜单、关键帧和骨骼菜单）现在跟随你的主题，深色主题下不再显示为白色。
- 俄语：“UV-развёртки”改为“UV-карты”；窄窗口中的显示按钮会在提示中显示自己的名称。

**更新** 打开 设置 > 配置 > 检查更新 > 更新并重启，或从 MDLxL 页面下载完整的便携版 ZIP。
