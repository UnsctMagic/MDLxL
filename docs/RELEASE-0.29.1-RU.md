# MDLxL 0.29.1 - Срочное исправление

Слишком раздражало, чтобы не исправить.

**Исправления**

- Библиотека материалов и текстур: текстура, которая уже есть в модели, снова выбирается одним щелчком. Предпросмотр текстуры в редакторе или Добавить открывает небольшое окно с кнопкой для каждого материала, который уже показывает эту текстуру (например, Material 12 · geoset 18), и кнопкой Новый материал. Один щелчок выбирает и завершает; Escape закрывает только это окно. Выпадающий список и лишние кнопки в колонке сведений убраны.

**Обновление**  Откройте Settings > Configuration > Search for updates > Update and restart или скачайте полный переносимый ZIP с сайта MDLxL.
