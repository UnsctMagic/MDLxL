# MDLxL 0.29.2 - Corrección urgente

Tres correcciones más gracias a vuestros informes.

**Correcciones**

- OptimizeXL: la pregunta de Guardar ya no aparece cortada por el marco del retrato. Se ve la ventana completa, las vistas previas de detrás se oscurecen y las preguntas y el resumen de tamaño están totalmente traducidos.
- Citadel Paint: cada pestaña de modelo conserva su propia cámara. Cambiar a otro modelo y volver ya no restablece el ángulo ni el zoom, y la vista del editor ya no copia la cámara de la pestaña anterior al siguiente modelo.
- Archivo > Nuevo (y cerrar la última pestaña) ahora empieza con un modelo realmente vacío en lugar de un cubo inicial.

**Actualización**  Abra Settings > Configuration > Search for updates > Update and restart, o descargue el ZIP portátil completo desde la página de MDLxL.
