# MDLxL 0.28.0 - 骨骼影响视图、更清晰的外观设置、整理混乱、Paint 印章

## 运动

- 新显示模式**骨骼影响**，也是运动编辑器的默认视图。模型变成均匀的半透明虚影，骨架绘制在上方。所选骨骼直接移动的部分显示为橙色；通过子骨骼跟随移动的部分显示为浅橙色。
- 运动编辑器保留自己的视图。顶点和其他编辑器保留各自的视图（默认为线框）。
- **F** 在纹理视图和你在该编辑器中最后选择的视图之间切换：线框 ↔ 纹理，骨骼影响 ↔ 纹理。
- 在运动编辑器中，**骨骼**和**聚焦骨架**默认开启，**骨架**默认关闭。你更改的显示开关会在下次打开 MDLxL 时保留。
- **骨骼**开关由骨骼、运动和动画编辑器共用。即使骨骼关闭，聚焦骨架显示的骨骼也可以点击选择。
- 所有编辑器的右侧面板共用一个宽度，默认 240 像素。拖动面板左边缘调整宽度；双击边缘恢复默认。

## 设置 → 外观

- 外观每次只显示一页。在左侧列表中选择页面：预设、界面、视口、线框、顶点、骨骼与骨架、骨骼影响、控制器、列表与文件夹、四视图、编辑器辅助、Citadel Paint。
- **骨骼与骨架**：骨骼样式（立方体与渐变线、关节与锥体、棍状）、连接线样式（渐变、锥形）、骨骼、根骨骼、所选骨骼及其父骨骼和子骨骼的颜色，以及连接线和骨链高亮的粗细，并带实时预览。所选骨链以相同形状高亮。骨骼颜色重新跟随这些设置。
- **线框**：线框样式**所有边**或**隐藏线**（在线框视图中，网格背后的线显示为淡色虚线），以及隐藏线框的亮度。
- **骨骼影响**：虚影不透明度及其三种颜色。

## 整理混乱

- 打开时先按纹理分组列出模型内容：几何体、材质、差异和建议的修复。
- 由你选择要应用哪些修复；只应用所选的修复。

## Citadel Paint

- Silver Chainmail 等细节丰富的印章在放大或较小的 UV 区域上保持清晰，悬停时即可看到真实效果。
- 新增**涂抹**工具（N），位于擦除旁边：拖动以推开并涂抹已绘制的颜色。
- **复制纹理**（Ctrl+Alt+C）和**粘贴纹理**（Ctrl+Alt+V）可在 Photoshop 或 GIMP 之间来回传递绘制的纹理。
- **笔画**（Shift+Z）列出你的笔画；可以撤销或恢复单个笔画，之后的笔画保持不变。

## 锻造

- Shift+双击会把一个面添加到已选的面中。
- 切割沿面的轮廓进行，挤出保持最简几何：没有多余的点或细碎的三角形。

## OptimizeXL

- 当蒙皮顶点混合了一个缩放为零的骨骼时，Insanity Fixer 会发出警告。在游戏中这些顶点会被拉成长长的尖刺，即使模型在编辑器中看起来正常。警告会显示第一个受影响的动画，且从不修改模型。

## 编辑器

- MDL、MDX 和 Paint 项目文件在资源管理器中有自己的图标。在 设置 → 配置 → 文件图标 中选择。
- UV 编辑器打开时为展开状态。替换纹理时会重用现有的材质和纹理，而不是每次都添加新的副本。
- 在没有显卡的电脑上运行更流畅。
- 动画：切换标签后，可见性与颜色会跟随勾选的几何体；保持相机旋转时，动画控件也会保持显示。

## 修复

- 设置 → 配置 → 导入配置 重新可用。此前所有文件都会因“Conflicting shortcut G”被拒绝。
- 当前版本 Warcraft III（3.0.1）中的生成特效（例如骑士的血）重新可以预览。它们的模型现为 1800 格式。首次生成时不再让播放短暂卡住。
- 在运动编辑器中显示骨骼时，双击重叠的发射器又可以依次切换。
- “导入整个部件”（BitsAndParts）之后，一次撤销即可移除该部件。
- 较长的模型标签名称可被屏幕阅读器正确读出。
- 快速切换编辑器时偶发的预览错误已修复。
- 在深色主题中，节点列表所选行的次要标签清晰可读。
- MDX 导出不再为 Reforged 几何体写入 LevelOfDetail -1。
