# MDLxL 0.40.0

- **Sommets** — **Animé** (Maj+Espace) affiche une pose d’animation figée pendant que vous modifiez la pose de base. La flèche choisit une séquence. Un clic droit sur le bouton permet de choisir l’image. La tête de lecture de Mouvement reste indépendante.
- **Chaque pièce** se trouve à côté de **Contraintes du plan** dans Sommets et Forge. L’Éditeur UV conserve sa commande **Chaque pièce**.
- **Affichage** — Les repères d’axes sont disponibles dans les éditeurs de sommets, d’os, de mouvement et d’animations.
- **Éditeur UV** — **Aperçu RVB** colore le géoset actif dans l’aperçu. **Masquer Extras** conserve les géosets en cours de travail et masque les autres effets. L’aperçu montre le modèle sans animation. Les nouvelles installations utilisent le zoom vers la droite ou le haut. Les profils existants conservent leurs réglages.
- **EMTR** — L’aperçu commence avec l’émetteur sélectionné. **Afficher tous les émetteurs** affiche les autres. **Glow Up** distingue la lueur des héros des petits effets des yeux. **Examiner la lueur détectée** permet d’exclure ou de rétablir chaque élément.
- **FX** — Le réglage d’un effet déjà appliqué conserve les modifications de texture et d’UV. La bibliothèque de textures garde son aspect habituel dans FX et EMTR. Le style Éditeur du monde affiche chaque objet une seule fois.
- **Éditeurs de rig** — **Ensemble compact** dispose les géosets par rangée.
- **Console IA** — L’examen signale les erreurs déjà présentes dans le modèle de départ et continue de bloquer les nouvelles erreurs.

Recherchez les mises à jour dans les paramètres ou téléchargez le ZIP portable complet.
