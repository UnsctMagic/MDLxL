# MDLxL 0.21.1 — Полная загрузка и исправление обновления

В предыдущей версии была проблема с обновлением. Этот выпуск поставляется как новая полная загрузка MDLxL и содержит исправленный механизм обновления для будущих выпусков. Скачайте и распакуйте полный пакет с Low Polyworks.

- Предотвращает запуск старой сессии редактора во время установки обновления.
- Сохраняет настройки, личные библиотеки, сохранённые файлы и одну предыдущую версию для отката.
- Включает расширенные настройки форм Forge и Glow Up.
- Добавляет управление скоростью анимации и возможность восстановления исходного тайминга.
- Улучшает OptimizeXL, командные цвета UV, пресеты материалов, Showcase, вращение камеры и редактирование эффектов.
- Включает параметры сохранения данных редактора.
