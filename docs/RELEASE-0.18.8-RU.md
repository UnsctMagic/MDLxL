# MDLxL 0.18.8 — Исправление сохранения MDX

- Модели с пустыми группами привязки к костям теперь сохраняются в MDX без ложной ошибки `Save verification failed: serialization changed ... Geosets[n].Groups`.
- При открытии и повторном открытии MDX сохраняются пустые группы, порядок групп, идентификаторы костей и привязки вершин к костям. Проверка сохранения остаётся включённой.
- Включены все изменения версии 0.18.7 и исправление сохранения из объединённого [PR #109](https://github.com/UnsctMagic/MDLxL/pull/109).

Скачайте **MDLxL-0.18.8-win32-x64.zip**, распакуйте весь ZIP и запустите **MDLxL.exe**. Все папки должны оставаться вместе. Архив соответствующего исходного кода FFmpeg доступен отдельно на странице релиза.
