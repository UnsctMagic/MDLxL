# MDLxL 0.27.0 - AnimXL、全新发射器编辑器、锻造直接塑形

## AnimXL（新功能，实验性）

- AnimXL 用类物理效果为模型的动画塑形。点击红色 ANIM 按钮或从模块菜单打开。
- AnimXL 是实验性功能：不同骨架的效果可能不同。保存前请检查动画；“应用为新动画”会保留原动画。
- 效果：缓入缓出、跟随延迟、回弹收势、重量、拖曳、次级运动、落脚冲击、预备动作、夸张、待机运动、停顿与反应、跌落模拟。预设：默认、重、敏捷、松弛、跌落。
- 效果可应用于整个骨架（自动），或只用于所选骨骼。用“选择片段”只改时间轴的一部分，片段外的关键帧保持不变。
- 双脚保持着地，双手握持保持在武器上，循环动画保持无缝。
- 用并排、原骨架、轨迹（骨骼末端划出的路径）和运动曲线对比效果。拖动姿势的菱形标记即可改变该姿势出现的时间。
- “应用”以一步撤销替换动画。“应用为新动画”保留原动画并新增一个动画。

## 发射器编辑器（EMTR）

- 粒子发射器从六个标签页减为两个：外观和运动。每项设置只出现一次。
- 生命周期内：一张表设定粒子在出生、中途和结束时的颜色、大小和透明度 %。
- 自动识别精灵图。帧选项列出游戏本身对这张图使用的方式（整个动画、前半段、静止帧、循环……）。“Custom…”可自己挑选帧。
- 丝带的设置集中在一个界面，只保留游戏中真正起作用的项。播放轨道显示丝带何时可见：拖动菱形标记，“+”可再添加一段。
- 平滑大小：右键点击播放轨道，拖动绿色端点，然后点“应用”。丝带会在关键帧之间平滑变大或变小。
- 新丝带在刀刃处最亮，向尾部逐渐淡出。
- 手动调整显示任意发射器的精确 MDL 文本。把鼠标移到高亮的词上即可看到它的含义。

## 锻造

- 锻造打开时显示网格，形状直接立在网格上。
- 双击一个面即可选中，并直接进入移动。按住 E 拖动即可挤出，松开后回到移动。
- 切割可等分，也可在点击处切开，作用于所选面或整个形状。
- 弯曲、膨胀/收缩、锥化、倒角和扭转现在是视图中的控制柄。拖动金色控制柄；✓ 保留更改，Esc 取消。

## 动画

- 现在可以在全局动画中移动、旋转和缩放骨骼。
- 保存新的全局动画时，它会放在 MdlVis 查找的位置：紧接在动画列表之后。

## 编辑器

- 关闭工作平面时：移动工具现在在顶点编辑和锻造中也会显示 POSE 的箭头和方块。拖动箭头沿一个轴移动，拖动方块在一个平面内移动，可替代 Shift + XY/ZX/YZ。
- 模型标签：打开很多模型时，标签会缩短并显示“…”（名称结尾仍然可见），当前标签显示完整名称。不再有滚动条，可用鼠标滚轮或小箭头滚动。
- 从资源管理器把文件拖到 MDLxL 上，效果与“文件 > 打开”相同：能找到模型旁边的纹理，“保存”写回原文件，最近文件会记住它，多个模型各自在自己的标签中打开。
- 有未保存更改时关闭：保存在最上方，“取消？”为黄色，关闭为红色并单独放在下方。Esc 取消。
- UV 编辑窗口留在所属模型标签内，是一个可移动的小窗口。打开时顶点编辑器仍可使用。
- 在同一模型内复制粘贴几何体时保留原来的骨骼。
- POSE 会隐藏只是重复身体控制柄的骨盆控制柄。

## 修复

- 一些编辑过的模型无法保存（“Save verification failed … PivotPoints”）。现在可以正常保存。
