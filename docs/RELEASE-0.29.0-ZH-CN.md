# MDLxL 0.29.0 - Attachemator、魔兽争霸 III 库、Glow Up、肖像背景

## Attachemator

- 骨骼模式 → 工具中的新功能。把标准附加点（Origin、OverHead、Head、Chest、双手、双脚、坐骑的后脚、Weapon）放到正确的骨骼上，和暴雪自己的单位一样。
- 已有的附加点按名称识别，移动并重新指定父级；已经正确的点保持不动。
- 预览窗口显示所有附加点。取消勾选某个点可保持原样，也可以用普通的移动手柄拖动它。点击**应用**之前不会做任何更改，应用只占一步撤销。

## 魔兽争霸 III 库

- **LIBR** 按钮打开整个游戏：**纹理**、**模型**、**声音**和**所有文件**选项卡，并带版本筛选（Classic、Reforged、Forsaken Kingdom 等）。
- 模型可以按**世界编辑器样式**浏览（种族 › 单位、英雄、建筑、法术、物品、装饰物，每项带游戏图标），也可以按游戏自身的文件夹浏览。
- 在约 175,000 个文件中即时搜索。搜索 `painting`、`art` 或 `loading screen` 只会找到游戏的插画。
- 模型显示可旋转的 3D 预览和动画选择。双击或点击**在编辑器中打开**会在新标签页中打开。点击声音即可播放；任何文件都可以用**另存副本…**导出。
- 如果模型中已有该纹理，添加时会询问：**使用现有材质**还是**新建材质**。
- 纹理选择器（Replace Texture、Material Manager、EMTR、Forge、Citadel Paint）保持不变。

## Glow Up（现在位于 EMTR）

- Glow Up 从 Forge 移到 EMTR，位于“添加丝带”旁边。它按照暴雪英雄的方式制作英雄光效：脚下三个脉动的队伍光晕平面，以及沿武器排列的一排光晕方块。
- 提供 Origin glow 和 Weapon glow 开关（可选择武器）以及 Brightness 滑块。像发射器一样在预览中拖动手柄来调整光效的大小和位置；预览可用鼠标旋转。**创建**只占一步撤销。

## 肖像背景

- 肖像工具栏（运动和动画）中的 **Add Background** 会在模型后面添加魔兽风格的队伍颜色背景，并像暴雪 SD 肖像那样针对所选镜头放置。它只在 Portrait 动画中显示。
- 如果模型已有背景，按钮显示为 **Refresh Background**，会为当前镜头重新放置。
- **▾** 打开大小和高度滑块、游戏裁切的小预览以及 **Blizzard default**。

## OptimizeXL

- **全部修复**会修复检查器报告的所有问题，一次预览全部修复并再次检查。**批准全部修复**保留这些修复。需要决定的问题会提供带默认值的**选择**。
- 之前和之后的预览并排显示。
- **保存**把结果写入当前打开的模型（一步撤销）。第一次保存时会提供**先备份再保存**。

## Forge

- 把挤出或倒角复制或镜像到同一形状上，并用移动、旋转和工作平面放置。**磁铁**手柄让它贴合表面。
- 按住 **Shift** 可让切割和挤出吸附到相匹配的位置。**混合**把相邻的平面合并，使其作为一个表面挤出。

## 编辑器

- **透视图**缩放：缩小时镜头向后移动，而不是加宽镜头视角，近处的部分不再被拉伸到整个屏幕。
- **声音事件**列出游戏中的所有声音，按用途分组（法术、武器与投射物、单位……），并带 ROC / TFT / RE / FK 筛选。血迹和脚印事件只列出各自的类型。
- **外观 → 骨骼与骨架**分开提供骨骼样式（立方体、菱形）和骨架样式（渐变、锥形、圆锥、棍状）。
- UV 编辑器：小键盘可向八个方向移动所选 UV。
- 编辑时旋转镜头，面向镜头的骨骼上的发射器不再移动。高亮关键帧也会显示发射器的可见性关键帧。

## 修复

- 深色主题下，骨骼 / 辅助对象 / 参考点标签清晰可读。
- POSE 可以再次点击辅助对象标记（例如 Footman 的头部）。
- 在动画名称上滚动滚轮时，侧面板不再同时滚动。
